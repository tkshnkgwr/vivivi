# vivivi: Security Policy (SECURITY)

## 1. Security Philosophy
`vivivi` is implemented in Rust. Through Rust's strict ownership and type system, common C/C++ memory vulnerabilities are eliminated by default:
- Buffer overflows
- Use-after-free
- Double-free errors
- Data races

---

## 2. Reporting Vulnerabilities
If you discover a security vulnerability, please report it privately to the repository maintainer instead of filing a public issue.
We will address it promptly.
