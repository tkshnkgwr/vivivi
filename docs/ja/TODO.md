### フェーズ 4: メインエディタ化＆ViVi高度機能の実装 (`vivivi-vi`, `vivivi-modes`, `vivivi-app`)

ボスの日常使い（メインエディタ化）に向けて、Gvim常用機能およびViVi 3/4・OpenViViの高度編集機能を順次実装します。

#### 4.1 ボス最優先：実務常用機能（Gvim互換・レイアウト）
- [x] **画面分割・マルチビュー (`:split`, `:vsplit`, `Ctrl-w`)**
  - 同一バッファまたは複数バッファの上下（水平）・左右（垂直）分割表示
  - ウィンドウ間のフォーカス移動 (`Ctrl-w h/j/k/l`)、リサイズ
- [x] **BOX選択・矩形編集の完全対応 (`VisualBlock` / `Ctrl-v`)**
  - 矩形選択範囲の削除 (`d`, `x`)、ヤンク (`y`)
  - 矩形一括文字挿入 (`I`, `A`)
  - 矩形ペースト（複数行にまたがる矩形貼り付け）
- [x] **アウトライン解析・サイドペインツリー**
  - Markdown見出し階層、および主要言語（Rust, C++等）の関数・構造体ツリー解析
  - トグル表示可能なサイドペインと該当行への即時ジャンプ

#### 4.2 ViVi固有キラー編集支援機能 (`vivivi-modes`)
- [ ] **罫線保護編集 (Keisen Protected Edit)**
  - 罫線枠内でのテキスト入力・削除時、右側空白を自動伸縮して外枠罫線を崩さない保護機能
- [ ] **テキストアライン (文字列揃え)**
  - 指定文字（`=` や `:` 等）の位置で複数行を垂直一括整列
- [ ] **リナンバ (箇条書き・行番号再付番)**
  - 連番リスト（`1.`, `2.` 等）の自動再ナンバリング
- [x] **文字列変換機能**
  - 全角 ⇄ 半角（英数・カナ）、ひらがな ⇄ カタカナ、大文字 ⇄ 小文字の一括変換

#### 4.3 ツール機能・拡張性 (ViVi 3 / ViVi 4 準拠)
- [ ] **プロジェクト内Grep検索 (`:grep`, ripgrep採用)**
  - Rust製超高速検索エンジン `ripgrep`（`grep-searcher`/`ignore` クレート連携）を採用
  - 検索結果リストペイン（ファイル・行番号・一致行）の表示と、該当箇所への即時ジャンプ
- [ ] **2文書比較・差分表示 (Side-by-Side DIFF)**
  - 左右分割画面での差分行・差分文字ハイライト (`similar` クレート連携)
- [ ] **印刷プレビュー & PDF印刷 (ViVi 3 / ViVi 4 準拠)**
  - 物理プリンタではなく **PDF出力（PDF印刷）** をサポート（用紙サイズ、行番号、ヘッダー/フッター付与）
  - **Markdown印刷プレビュー**: Markdownファイルの場合はプレビュー画面を印刷プレビューとして機能させ、見出し・装飾・テーブルの整形レイアウトを確認可能
  - プレーンテキスト／ソースコードのページ分割印刷プレビュー
- [ ] **デスクトップGUI (egui / eframe) フロントエンド**
  - フェーズ3より後ろ倒し。リッチなグラフィック罫線・フォントレンダリング
