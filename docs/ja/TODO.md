## 0. OpenViVi と ViVi の機能ルーツと役割分担 (Lineage & Architecture)

本プロジェクト（`vivivi`）は、津田伸秀氏による Windows 向け高機能テキストエディタ「**ViVi**（ViVi 3 / ViVi 4）」の豊富な実用・編集支援機能と、vivisuke氏による C++ / Qt 再構築プロジェクト「**OpenViVi**」の優れたデータ構造・UI設計思想を、現代の **Rust** で統合再構築するものです。

### 🏷️ 由来（ルーツ）の分類
- **【OpenViVi 由来】**: メモリ効率・並行性に優れたデータ構造（`GapBuffer`, `UndoMgr`, `ViewLineMgr`）およびモダンGUI/UX表現（ミニマップ、変更行ガター表示、落下アニメーション等）。
- **【ViVi 3 / ViVi 4 由来】**: 長年培われた独自のキラー編集支援（罫線保護編集、インラインCSV、式置換、BOX計算、リナンバ）、高速入力支援（動的補完 dabbrev、ダイナミックマクロ、LexEdit、Zen-Coding）、独自viコマンド拡張（Migemoローマ字検索、fFtT全角マッチ、数値増減、真偽値トグル）、強力なファイル管理（世代バックアップ DiffLog、コード内ToDo抽出、2ペインファイラー）。
- **【共通・統合】**: Unicode罫線自動結合、シンタックスハイライト、アウトライン解析、Grep検索、2文書DIFF比較、画面分割など。
