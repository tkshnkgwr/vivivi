# vivivi: 開発者・AI指示書 (INSTRUCTIONS)

本書は、`vivivi` プロジェクトにおける開発者およびAIエージェント向けの行動ガイドラインおよび作業指示書です。

---

## 1. 最優先遵守ルール
本プロジェクトでは、リポジトリ直下の [**`RULES.md`**](../../RULES.md) が最優先の拘束力を持ちます。

1. **自動コミット/Pushの絶対禁止**: ボスからの明示的な指示がない限り、`git commit` や `git push` を自動実行しない。
2. **Markdownテーブル垂直整列**: すべての表組みは文字幅を考慮してパイプとハイフンを垂直整列する。
3. **呼称**: ボスのことは常に「ボス」とお呼びし、100%日本語で対応する。
4. **環境変数化原則**: ローカル絶対パスは `%USERPROFILE%` 等に統一し、生パスは自律的に補正する。
5. **高速CLIツールの標準利用**: `rg`, `fd`, `jq`, `bat --paging=never` を最優先で使用する。

---

## 2. 参照アセットの取り扱い
- `docs/references/` に展開された有償版ヘルプファイル（HTML）は、仕様調査用のローカルリソースです。
- ライセンス保護のため、Gitコミット対象から除外（`.gitignore`）されています。
