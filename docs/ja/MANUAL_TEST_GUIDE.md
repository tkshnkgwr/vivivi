# vivivi: 手動動作確認（受入テスト）チェックリスト (MANUAL_TEST_GUIDE)

本書は、`vivivi` のリリース（v0.1.0-alpha等）前や大型リファクタリング後に、人間（テスター／開発者）が実際に操作して操作感・表示崩れ・主要機能を五感で検証するための**手動動作確認チェックリスト**です。

---

## 🚀 準備と起動

```powershell
# 1. 最新バイナリのビルド
cargo build --release

# 2. 起動
.\target\release\vivivi.exe
```
