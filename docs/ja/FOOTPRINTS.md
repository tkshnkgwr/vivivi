# vivivi: リソース消費指標 (FOOTPRINTS)

本書は、`vivivi` のリソース消費量（RAM、CPU、起動時間、局所編集計算量）の実測値および目標指標を定義します。

---

## 1. パフォーマンス目標値 (Target Metrics)

| 指標                            |    目標値    | 目的                                  |
| :------------------------------ | :----------: | :------------------------------------ |
| **起動時間 (Cold Start)**       | **< 100 ms** | エディタ起動の知覚ラグ極小化          |
| **局所編集 (文字挿入/削除)**    |   **O(1)**   | GapBufferによるキー入力応答の超高速化 |
| **アイドル時 CPU 使用率**       |   **0.0%**   | キー入力待ち受け時の完全休止          |
| **メモリ消費 (小〜中規模文書)** | **< 20 MB**  | 軽量・軽快なフットプリントの維持      |
| **Undoブロック適用時間**        |  **< 5 ms**  | トランザクションUndoの即座な巻き戻し  |

---
