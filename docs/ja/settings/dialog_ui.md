## 1. GUI 設定パネル仕様（egui: 左右2ペイン・モーダルダイアログ）

ViVi 3/4 の多機能なプロパティシートを踏襲・洗練させ、モダンな左右2ペイン構成のフラットダイアログを提供します。

### UI ワイヤーフレーム

```
+--------------------------------------------------------------------------+
|  設定 (Preferences) - [Tokyo Night]                             [X] 閉じる|
+-------------------+------------------------------------------------------+
| [検索: _________] | [表示・外観 (Appearance)]                            |
|                   |                                                      |
| ▶ 1. 一般 (Gen)   |  カラーテーマ                 : [Tokyo Night        ▼]|
| ▼ 2. 表示・外観   |  行番号表示 (Line Numbers)    : [x] 有効              |
|    - 外観・テーマ |  相対行番号 (Relative Num)    : [ ] 無効              |
|    - ガター       |  右端折り返し (Word Wrap)     : [ ] 無効 (nowrap)     |
| ▶ 3. 不可視文字   |  変更行ガター強調             : [x] 有効              |
| ▶ 4. 入力・編集   |                                                      |
| ▶ 5. 独自ツール   | [GUI / フォント]                                     |
| ▶ 6. キーマップ   |  フォントファミリー           : [PlemolJP Console NF▼]|
|                   |  フォントサイズ               : [ 15.0 ] [▲][▼]      |
|                   |  文字削除落下アニメーション   : [x] 有効 (OpenViVi演出)|
|                   |  ミニマップ表示               : [x] 有効 (幅: 90px)   |
|                   |                                                      |
+-------------------+------------------------------------------------------+
| [デフォルトに戻す]                      [キャンセル]  [適用]  [保存して閉じる] |
+--------------------------------------------------------------------------+
```

### 操作特徴
- **インクリメンタル検索**: 左上の検索バーに入力することで、該当する設定項目がハイライトされ、目的のタブへ瞬時にジャンプ可能。
- **即時プレビュー（適用ボタン）**: ダイアログを開いたまま背景のエディタ画面でフォントサイズや行番号の変更結果を確認可能。
- **保存して閉じる**: 変更内容を `%USERPROFILE%\.vivivi\config.toml` へ即座に反映・永続化。

## 2. テーマ選択・リアルタイムプレビューUI

- **メニューバーからの直接切替**:
  - `[表示(V)] -> [カラーテーマ(T)] -> [OpenViVi / ViViClassic / TokyoNight / ViviviDark / ViviviLight]`
- **リアルタイム反映**:
  - メニュー選択と同時にエディタ全体の描画スタイルが即時切り替わり、`config.toml` のアクティブテーマが自動更新・保存されます。

---

## 3. TUI 設定画面仕様（Ratatui: 中央フローティングウィンドウ）

- **起動方法**: コマンドラインから `:preferences` または `:set`（引数なし）でポップアップ表示。
- **キー操作体系**:
  - `j` / `k`: 設定項目の上下移動
  - `h` / `l`: カテゴリの展開・折り畳み
  - `Space`: チェックボックス／トグル項目の切り替え
  - `Enter`: 数値・文字列項目の入力開始および確定
  - `Esc` / `q`: ダイアログを閉じる

---

## 4. コマンドライン実行と永続化の境界ルール

コマンドライン（Exコマンド）からの設定変更やテーマ変更と、ファイル永続化の境界について以下のルールを定めます。

| 操作方法                  | コマンド例                             | 適用範囲           | `config.toml` への影響           |
| :------------------------ | :------------------------------------- | :----------------- | :------------------------------- |
| **一時変更 (Exコマンド)** | `:set nonumber`<br>`:colo openvivi`    | **現在のセッション限定** | **書き込まない**（再起動で復元） |
| **恒久保存 (Exコマンド)** | `:mkvivivirc`<br>`:wconfig`            | **永続化**         | **即時上書き保存**               |
| **設定画面ダイアログ**    | `[保存して閉じる]`                     | **永続化**         | **即時上書き保存**               |
| **外部ファイル再読込**    | `:source` / `:so`                      | **現在のセッション** | ディスクの最新状態を再読込       |
