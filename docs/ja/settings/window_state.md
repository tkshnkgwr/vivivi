# GUI ウィンドウ状態の自動記憶・復元仕様書 (`window_state.json`)

> [!IMPORTANT]
> 本書は、`vivivi-gui`（デスクトップ GUI 版）におけるウィンドウ表示位置、ウィンドウサイズ、および最大化状態の永続化と安全な復元プロトコルの詳細仕様書です。
> 親仕様書: [設定管理ハブ (SETTINGS_DESIGN.md)](../SETTINGS_DESIGN.md)

---

## 1. 概要と目的

デスクトップ GUI エディタとしての快適な操作性を担保するため、エディタ終了時のウィンドウ状態（座標、幅・高さ、最大化フラグ）を自動記憶し、次回起動時に寸分たがわずに復元します。
この情報はユーザーの意図的な設定（`config.toml`）とは分離し、非設定キャッシュ情報として `%USERPROFILE%\.vivivi\cache\window_state.json` に保存されます。

---

## 2. データ構造 (`window_state.json`)

```json
{
  "x": 120.0,
  "y": 80.0,
  "width": 1280.0,
  "height": 800.0,
  "is_maximized": false
}
```

### フィールド一覧

| フィールド名   | 型         | デフォルト値 | 説明                                        |
| :------------- | :--------- | :----------- | :------------------------------------------ |
| `x`            | `f32`      | (画面中央)   | デスクトップ上の表示開始 X 座標 (px)        |
| `y`            | `f32`      | (画面中央)   | デスクトップ上の表示開始 Y 座標 (px)        |
| `width`        | `f32`      | `1024.0`     | 通常表示時のウィンドウ幅 (px, 最小: 640.0)  |
| `height`       | `f32`      | `768.0`      | 通常表示時のウィンドウ高さ (px, 最小: 480.0) |
| `is_maximized` | `bool`     | `false`      | 前回終了時にウィンドウが最大化されていたか |

---

## 3. 安全ガード（マルチモニター切断対策・フェイルセーフ）

外部ディスプレイの切断や解像度の変更により、「記憶された座標が現在のデスクトップ表示領域外に取り残されて開けない」というトラブルを防ぐため、以下の安全ガードを必須とします。

1. **画面内包判定**:
   - 起動時、取得した `(x, y)` がプライマリモニターおよび接続中のサブモニターの有効デスクトップ領域内にあるかを検証。
2. **安全フォールバック**:
   - 座標が完全に画面外、またはウィンドウの 80% 以上が画面からはみ出している場合、座標指定を破棄し、自動的に **プライマリモニターの中央（デフォルトサイズ: 1024×768）** に安全に表示。

---

## 4. 実行ライフサイクル（読込と保存）

```
【起動時 (main.rs)】
1. %USERPROFILE%\.vivivi\cache\window_state.json を読み込み
2. 安全ガード判定を実施
3. eframe::NativeOptions の ViewportBuilder へ適用:
   - with_position([x, y])
   - with_inner_size([width, height])
   - with_maximized(is_maximized)

【終了時 (ViviviGuiApp::save / on_exit)】
1. 現在のウィンドウ座標・サイズを取得
2. 最大化されている場合は最大化前の通常矩形サイズを保持
3. %USERPROFILE%\.vivivi\cache\window_state.json へ書き込み
```
