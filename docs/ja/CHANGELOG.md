## [0.9.18-beta] - 2026-11-11

### Added / Improved
- **コマンドライン（`:`）および検索（`/`・`?`）履歴の上下選択機能 (`vivivi-vi`, `vivivi-app`, `vivivi-gui`)**:
  - `CommandParser` に Exコマンド用履歴（`ex_history`）と検索パターン用履歴（`search_history`）を独立して最大 100 件保持する機構を実装（重複排除・最新順ソート対応）。
  - コマンドラインモード中に `↑` / `↓` キー（または `Ctrl+P` / `Ctrl+N`）で過去に入力したコマンドや検索語を遡って呼び出し可能に強化。
  - 途中まで入力した文字列（例: `:set`）がある状態で `↑` を押した際の前方一致プレフィックス絞り込み巡回、および最下段まで戻った際の入力途中ドラフト文字列への自動復帰に対応。
  - GUI 版（`vivivi-gui`）において、メニューやサイドバー操作後に `egui` のウィジェットフォーカス移動に矢印キーが奪われないよう自動フォーカス解放ガードを追加。

  - `:hex`, `:binary`, `:text` Exコマンド、`Tab` ペイン切替、上位/下位ニブル直接編集、ASCII直接置換、Undo/Redo、バイト検索を TUI および GUI の双方へ統合。

- **Tree-sitter 構文木ハイライト & スマート選択統合 (`vivivi-modes::treesitter`, Phase 5)**:
  - `tree-sitter` (0.24) および `tree-sitter-rust` (0.23) による抽象構文木（AST）解析とインクリメンタルパース（`edit` API）を統合。
  - エディタ描画（TUI `editor.rs` / GUI `canvas.rs`）における AST 多層レイヤリングハイライト連携。
  - 構文木ノード階層に沿ったスマート選択拡大・縮小（`Alt+Up` / `Alt+Down`, `:smartselect [expand|shrink]`）および AST S式プレビュー（`:ast`）を実装。

## [0.9.14-beta] - 2026-11-06

### Added / Improved
- **サイドバー・ファイルエクスプローラー非同期クラウド耐障害強化 (`async_tree.rs`, ViVi 4 / モダン拡張)**:
  - **ワーカースレッドによる完全非同期走査**: `std::thread::Builder` と `std::sync::mpsc` チャネルにより、OneDrive や SMB 共有の I/O 遅延があっても GUI スレッドを 1ms もフリーズさせないアーキテクチャを確立。
  - **2.0秒タイムアウト監視と耐障害 UI**: 応答が遅延した場合は自動で `Timeout` 状態へ遷移し、スピナー、警告バッジ、および「再試行」「親ディレクトリへ戻る」ボタンを表示。
  - **Windows リパースポイント / クラウドオンデマンド属性の安全検知**: `symlink_metadata` により、未ダウンロードの実体を強制ロードさせずにクラウドプレースホルダー（☁ アイコン）として安全に描画。
  - **ショートカット & Ex コマンド体系**: `Ctrl+e` によるエクスプローラー開閉トグル、および Ex コマンド `:tree`, `:Explore` を新設。
- **プロジェクト可視化グラフ (`visualize.rs`, ViVi 4 準拠)**:
  - **2D 力学モデル (Force-Directed Graph)**: クーロン斥力（ノード重なり防止）とバネ引力（階層エッジ）、中心重力、および摩擦減衰（Damping 0.85）による物理シミュレーションを構築。
  - **ファイルサイズ & 更新鮮度の可視化**: ファイルサイズの対数スケール半径（14px〜36px）と、更新日時の鮮度に応じた発光カラー（直近1時間はシアン、24時間はゴールド、1週間はブルー）、および拡張子別の外枠色分け。
  - **省電力ハイブリッド制御**: 全ノード運動エネルギー収束で物理演算をスリープさせ、アイドル時の CPU 使用率 0% を維持。
  - **インタラクション & ワンクリックオープン**: ノードのドラッグ・ピン留め、キャンバスのパン・ズームに対応し、ファイルノードをクリックすると即座にエディタで開き通常編集へシームレス復帰。
  - **コマンド & メニュー統合**: Ex コマンド `:visualize`, `:graph`、およびメニューバー「View」→「Visualize (Project Graph)」を追加。

## [0.9.13-beta] - 2026-11-06

### Added / Improved

  - **キラー機能ベンチマーク配備**: `UndoMgr` 1,000回操作、文字コード早期判別、1,000行 CSV 列幅計算、Migemo ローマ字検索、Unicode 罫線自動結合、Trim 速度のシナリオを配備。
- **行トリミング・末尾空白一括削除 (`:trim`, ViVi 4 準拠)**:
  - **末尾空白トリミングモジュール新設 (`trim.rs`)**: 半角空白 (`' '`)、タブ (`'\t'`)、全角スペース (`'　'`, `\u{3000}`) をゼロコピーで高速トリミング。
  - **多彩な Ex コマンド体系**: `:trim`, `:%trim`, `:'<,'>trim`, `:[range]trim` および空白種別指定（`half`, `zenkaku`）。
  - **保存時自動トリミング連動**: `config.editing.trim_on_save` 設定および `:set trim` / `:set notrim` により、`:w` 保存直前に自動トリミングしてクリーンな状態でディスク永続化。
  - **完全な Undo トランザクション保証**: 複数行の一括トリムであっても単一 Undo ブロックに記録され、`u` キー1回で直前の状態に完全復元可能。
- **外部プロセス連携拡張 & 実行ダイアログ (`cmdExecDlg`, ViVi 4 準拠)**:
  - **コマンド出力読み込み挿入 (`:r !<cmd>`, `:read !<cmd>`)**: 外部コマンドの出力をカレント行の次行（または指定行）へ直接バッファに挿入・展開（Undo対応）。
  - **行範囲フィルター置換 (`:[range]!<cmd>`, `:'<,'>!<cmd>`)**: 指定行範囲や選択行をプロセスの標準入力へ流し込み、標準出力で一括置換。
  - **外部コマンド実行ダイアログ新設 (`cmdExecDlg` / `:cmdexec`, `:cmd`)**: TUI フローティングモーダルから対話的にコマンドを入力し、Tab キーで「1. 実行のみ」「2. バッファ挿入 (:r!)」「3. 選択行置換 (:[range]!)」を切り替えて即時実行・プレビュー可能。
- **テスト堅牢化・メモリ安全性向上**:
  - **クリップボード並行ヒープ破壊対策**: `MockClipboard` を新設し、テスト実行時の Windows API OLE競合（`STATUS_HEAP_CORRUPTION: 0xc0000374`）を根本解消。
  - **Box::leak メモリリーク排除**: `zenkaku_space` の型を `Cow<'static, str>` に移行し、コードベースから `Box::leak` を完全排除。
  - **実機環境ファイルアクセス分離**: テスト実行時の `%USERPROFILE%\.vivivi` 配下への読み書きをインメモリでサンドボックス化。
  - **TUI 設定画面キャンセル時ロールバック保証**: `Esc` / `q` で閉じた際に開く直前の設定へ完全復元する処理を統一。
