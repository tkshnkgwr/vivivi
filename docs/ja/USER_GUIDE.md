# vivivi: ユーザー利用ガイド (USER_GUIDE)

本書は、`vivivi` エディタの基本操作方法、モード切替、および独自機能（CSVモード、罫線モード）の操作方法を解説します。

---

## 1. 基本操作 & モード体系

| モード名       | 切替キー             | 役割・操作                                                   |
| :------------- | :------------------- | :----------------------------------------------------------- |
| **Normal**     | `Escape`             | 移動、削除、ヤンク、コマンド実行の基点                       |
| **Insert**     | `i`, `a`, `o`, `O`   | 通常の文字入力（連続入力はUndoで1ステップに統合）            |
| **Visual**     | `v` / `V` / `Ctrl-V` | 文字単位選択 / 行選択 / 矩形ブロック選択                     |
| **Command**    | `:`                  | ファイル保存 (`:w`)、終了 (`:q`)、置換 (`:s`)                |

---

## 2. 独自拡張モードの操作

### (1) インラインCSVモード
- カンマまたはタブ区切りのテキストを、各列の最大文字幅に合わせてインラインで自動整列します。
- 閲覧時はセルのクォート（`"` / `'`）が透過表示され、カーソル行のみ生テキストで安全に編集できます。

### (2) 罫線モード
- **モード切替**: `Shift-F5`
- **罫線を引く**: `Ctrl + 矢印キー`（上下左右の交点を自動結合して十字・T字等の適切な文字に変換）
- **罫線を消去**: `Shift + 矢印キー`
