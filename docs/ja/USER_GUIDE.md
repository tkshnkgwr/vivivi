# vivivi: ユーザー利用ガイド (USER_GUIDE)

本書は、`vivivi` エディタの基本操作方法、モード切替、独自編集支援、マクロ、およびAI連携機能の包括的な操作ガイドです。

---

## 1. 基本操作 & モード体系

| モード名       | 切替キー             | 役割・操作概要                                               |
| :------------- | :------------------- | :----------------------------------------------------------- |
| **Normal**     | `Escape`             | 移動、削除、ヤンク、コマンド実行の基点                       |
| **Insert**     | `i`, `a`, `o`, `O`   | 通常の文字入力（連続打鍵はUndoブロックで1操作に自動統合）    |
| **Visual**     | `v` / `V` / `Ctrl-v` | 文字単位選択 / 行選択 / 矩形ブロック選択                     |
| **Command**    | `:`                  | ファイル保存 (`:w`)、終了 (`:q`)、置換 (`:s`)、ex拡張コマンド|

---

## 2. 独自拡張モード＆ナビゲーション

### (1) インラインCSV/TSVモード
- カンマまたはタブ区切りのテキストを、各列の最大表示幅に合わせてインラインで自動垂直整列します。
- 閲覧時はセルのクォート（`"` / `'`）が透過表示され、カーソル行のみ生テキストで直接安全に編集できます。

### (2) 罫線モード & 罫線保護編集
- **モード切替**: `F5` または `Shift-F5`
- **罫線を描く**: `Ctrl + 矢印キー`（上下左右の交点を自動結合して十字・T字等の適切な文字に変換）
- **罫線を消す**: `Shift + 矢印キー`
- **罫線保護入力**: 罫線枠内で文字を入力・削除しても、右側の空白が自動伸縮し外枠を一切崩しません。
- **枠内テキスト整列**: `:align left`, `:align center`, `:align right`

### (3) 画面分割・マルチビュー (Split / Vsplit)
- **水平分割**: `Ctrl-w s` または `:split` (`:sp`)
- **垂直分割**: `Ctrl-w v` または `:vsplit` (`:vs`)
- **ウィンドウ巡回**: `Ctrl-w w`（または `Ctrl-w` に続けて `h`/`j`/`k`/`l`）
- **アクティブ閉鎖**: `Ctrl-w c` または `:close`
- **単一ウィンドウ化**: `Ctrl-w o` または `:only`

### (4) アウトライン解析ペイン (`F8`, `:outline`)
- `F8` または `:outline` で画面左側にシンボルツリーペインを表示。
- Markdownの見出し（`#`）、Rust（`fn`, `struct`, `impl`）、C/C++、Pythonの定義を自動抽出。
- `j` / `k` で項目を選び、`Enter` で該当行へジャンプ。`Ctrl-w` でエディタとフォーカス切り替え。

### (5) ローマ字日本語検索 (Migemo / `g/`)
- ノーマルモードで `g/` を打鍵すると、IMEオフのままローマ字（例: `g/kensaku`）で日本語（「検索」「けんさく」）をダイレクト検索。
- `Enter` で確定後、`n` で次の一致、`N` で前の一致へジャンプ。

### (6) クリップボード履歴ダイアログ (`F6`, `:cbhist`)
- `F6` または `:cbhist` で過去のヤンク・コピー履歴一覧をポップアップ表示。
- `j` / `k` で履歴アイテムを選択し、`Enter` で現在カーソル位置へ即座にペースト。

### (7) 文字種一括変換 (`conv`)
- 全角英数 $\to$ 半角: `:hankaku`（選択範囲またはバッファ全体）
- 半角英数 $\to$ 全角: `:zenkaku`
- ひらがな $\to$ カタカナ: `:katakana`
- カタカナ $\to$ ひらがな: `:hiragana`
- 半角カナ $\to$ 全角カタカナ: `:zenkata`
- 全角カタカナ $\to$ 半角カナ: `:hankata`
- 大文字 / 小文字変換: `:toupper` / `:tolower`

### (8) BOX選択数値集計 (`calc`)
- `Ctrl-v` で数値列を矩形選択し、`:calc` または `:sum` / `:total` を実行。
- 選択範囲内の数値を集計し、件数・合計・平均・標準偏差をステータス行に表示＆クリップボードへコピー。

### (9) ViVi独自vi拡張コマンド & ナビゲーション
- **fFtT 全角文字自動マッチ**: `f`, `F`, `t`, `T` で半角英数記号を入力した際、対応する全角文字（数字、括弧 `（）`、記号 `：！`）へも自動的にマッチしてジャンプ（`;` で順方向、`,` で逆方向繰り返し）。
- **カーソル単語前後検索 & 一致検索**:
  - `*` / `#`: カーソル位置の単語を完全一致（`\bword\b`）で前方／後方検索。
  - `g*` / `g#`: 単語境界なし（部分一致）で前方／後方検索。
  - `g<` / `g=`: カーソル下の単語を前方一致（プレフィックス）／後方一致（サフィックス）で前方検索。
- **数値・英字増減 & 真偽値トグル**:
  - `#+` / `##`: 数値の加算（+1）、英字の順送り（`a` $\to$ `b`）。
  - `#-`: 数値の減算（-1）、英字の逆送り（`b` $\to$ `a`）。
  - `#!`: 真偽値の反転トグル（`true` ⇄ `false`, `yes` ⇄ `no`, `on` ⇄ `off`）。
- **直前編集位置復帰 & 前行文字列複製**:
  - `@`: 直前に文字の入力・削除・置換を行った座標へ即座に復帰ジャンプ。
  - `'@` / `` `@ ``: 直前に編集した行の先頭へジャンプ。
  - `=<char>`: 直前の行の同列位置から指定文字 `<char>` までの文字列をカレント行へ複製挿入。
- **マーク機能**:
  - `ma`〜`mz`: カレントバッファ内のローカルマーク登録。
  - `mA`〜`mZ`: ファイルパスを保持する大文字の永続グローバルマーク登録。
  - `'a` / `` `a ``: マークした行・列へジャンプ。
  - `:marks`: 登録済みマーク一覧の表示。
- **タグジャンプ**:
  - `Ctrl-]` / `:tag <name>`: カーソル下の関数・構造体・変数シンボルの定義位置へジャンプ（`tags` ファイル探索および同一バッファ構文解析フォールバック）。
  - `Ctrl-t` / `Ctrl-[`: タグスタックをポップし、ジャンプ前の位置へ復帰。
  - `:tags`: タグジャンプ履歴スタックの一覧表示。

## 3. 高度編集支援 & 高速マクロ操作

### (1) テキストアライン (`:align <記号>`)
- **コマンド**: `:align =`, `:align :`, `:align ,`, `:align //` 等
- **操作**: 揃えたい複数行（またはビジュアル選択範囲）でコマンドを実行すると、指定した記号のカラム位置が垂直にピシッと揃います。

### (2) リナンバ (連番再付番 / `:renumber`)
- **コマンド**: `:renumber [start] [step]` または `:renum [start] [step]`
- **操作**: `1.`, `2)`, `(1)`, `[1]` 等の連番リストを選択して実行すると、インデントを維持したまま指定開始番号から等差増分で綺麗に再採番します（例: `:renumber 1 1`, `:renum 10 10`）。

### (3) 行頭・行末一括挿入 (`:insbeg`, `:insend`, `:begend`)
- **行頭挿入**: `:insbeg // `（インデントを保持して空行以外の行頭に一括挿入）
- **行末挿入**: `:insend ;`（行末に一括挿入）
- **両端一括挿入**: `:begend <li> </li>`（行頭と行末を同時にタグ等で囲む）

### (4) 動的単語補完 (dabbrev / `Ctrl-l`, `Ctrl-m`)
- 挿入モード中、単語の頭を数文字入力して `Ctrl-l` を押すと、バッファ内から候補を後方・前方走査して補完。
- `Ctrl-l` で次候補へ、`Ctrl-m` で前候補へ巡回。

### (5) 静的略語展開 (abbrev / `Ctrl-;`, `Alt-;`, `F4`)
- 挿入モード中、略語（例: `fn`, `struct`, `hw`, `todo`）の直後で `Ctrl-;`（または `Alt-;` / `F4`）を押すとスニペットへ瞬時に展開。
- **略語の動的登録**: `:abbrev <key> <value>`（例: `:abbrev hw Hello World!`）

### (6) ダイナミックマクロ (増井式リピート / `Alt-m`, `Ctrl-Alt-m`)
- 事前の記録開始操作が一切不要なインテリジェントマクロ。
- 同じ編集や入力を2回繰り返した直後に `Alt-m` を押すと、直前の反復パターン（XX）を推測して自動実行。
- 連続して `Alt-m` を押すことで、何回でも続けて反復適用可能。

### (7) 字句編集予測 (LexEdit / `Ctrl-j`)
- 単語の編集や置換を行うと履歴が蓄積されます。
- 類似の単語上で `Ctrl-j` を押すと、編集の意図を推測して次の置換を即座に適用（例: `old_user` $\to$ `new_user` の後、`old_role` 上で `Ctrl-j` を押すと `new_role` へ置換）。

### (8) Zen-Coding (Emmet) 展開 (`Ctrl-,`, `Alt-,`, `:zen`)
- 挿入モード中、HTML短縮記法（例: `ul#nav>li*3>a` や `div.container`）の直後で `Ctrl-,` または `Alt-,` を押すと、正規の入れ子HTMLタグ構造へ一括展開。

### (9) キーボードマクロ記録・再生 (`Ctrl-Alt-r`, `Ctrl-Alt-p`, `F9`, `F10`)
- **ワンタッチ記録**: `F9` または `Ctrl-Alt-r` で記録開始／終了をトグル。
- **ワンタッチ再生**: `F10` または `Ctrl-Alt-p` で直前のキー操作列を一括高速再生。
- Vi標準の `qa` ... `q` および `@a`, `@@` にも完全対応。

### (10) 式置換 (`:s/pattern/expression/e`, `:%s/pattern/expression/e`)
- **コマンド**: `:s/pattern/expression/e` または `:%s/pattern/expression/e`
- **概要**: 置換後文字列を算術式・スクリプト式として動的評価し、計算結果で置換します。
- **使用例**:
  - **価格の消費税計算（10%加算）**:
    `:%s/price: (\d+)/"price: " + int($1 * 1.1)/e`
  - **連番リナンバ**:
    `:%s/item/"item_" + $i/e` （`item_1`, `item_2`, ... へ置換）
  - **行番号プレフィックス付与**:
    `:%s/^/"Line " + $line + ": "/e`

## 4. AI連携機能 (`:ai`)

- **自然言語編集**: `:ai <指示>`（ビジュアル選択範囲や現在ブロックを自然言語でリファクタリング）
- **コミットメッセージ生成**: `:ai commit`（`git diff` から規約に沿ったコミットメッセージを一時バッファに生成）
- **詳細アーキテクチャ**: [`docs/ja/AI_INTEGRATION_DESIGN.md`](./AI_INTEGRATION_DESIGN.md) を参照。

---

## 5. ヘルプビューア (`F1`, `:help`)

- `F1` または `:help` で内蔵ヘルプドキュメントを表示。
- `:help keisen`, `:help csv`, `:help calc`, `:help dabbrev` 等でトピック別ヘルプを直接閲覧可能。
- `j` / `k` でスクロール、`q` または `Esc` でエディタへ復帰。
