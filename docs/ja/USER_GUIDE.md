# vivivi: ユーザー利用ガイド (USER_GUIDE)

本書は、`vivivi` エディタの基本操作方法、モード切替、独自編集支援、マクロ、およびAI連携機能の包括的な操作ガイドです。

---

## 1. 基本操作 & モード体系

| モード名    | 切替キー             | カーソル形状 | 役割・操作概要                                                         |                                                                                  |
| :---------- | :------------------- | :----------: | :--------------------------------------------------------------------- | :------------------------------------------------------------------------------- |
| **Normal**  | `Escape`             | ブロック (█) | 移動、削除、ヤンク、コマンド実行の基点                                 |                                                                                  |
| **Insert**  | `i`, `a`, `o`, `O`   |   縦線 (\    | )                                                                      | 通常の文字入力・Tabキーによるタブ挿入（連続打鍵はUndoブロックで1操作に自動統合） |
| **Replace** | `R`                  |   下線 (_)   | 1文字ずつ上書き置換入力（Tabでタブ置換、`Esc` でノーマルモードへ復帰） |                                                                                  |
| **Visual**  | `v` / `V` / `Ctrl-v` | ブロック (█) | 文字単位選択 / 行選択 / 矩形ブロック選択                               |                                                                                  |
| **Command** | `:`                  | ブロック (█) | ファイル保存 (`:w`)、終了 (`:q`)、置換 (`:s`)、ex拡張コマンド          |                                                                                  |

> [!NOTE]
> **端末カーソル形状の自動連動**: Vim/Gvim の伝統に準拠し、モード遷移に応じて端末カーソルの形状（ブロック／縦線／下線）がリアルタイムに切り替わります。エディタ終了時や異常終了時も端末デフォルト形状へ自動復帰します。

> [!TIP]
> **80文字超長行での水平スクロール自動追従と折り返し制御**:
> 通常時は `:se nowrap`（折り返しなし・水平スクロール追従）状態です。端末の画面幅（80桁等）を超える長い行でも、カーソル移動や `$`（行末移動）に合わせて画面が自動的に左右へスムーズに水平スクロールします。全角文字（幅2）やタブ文字（`tabstop` 設定幅）の実際の表示幅（Visual Column）を正確に計算し、全角文字の泣き別れやズレを起こさず適切にクリッピング描画されます。
> 画面端での行折り返し表示を行いたい場合は、`:se wrap`（`:set wrap`）を実行することで折り返し表示へ動的に切り替えられます（`:se nowrap` で水平スクロール復帰、`:se wrap?` で状態確認）。

## 2. 独自拡張モード＆ナビゲーション

### (1) インラインCSV/TSVモード
- カンマまたはタブ区切りのテキストを、各列の最大表示幅に合わせてインラインで自動垂直整列します。
- 閲覧時はセルのクォート（`"` / `'`）が透過表示され、カーソル行のみ生テキストで直接安全に編集できます。

### (2) 罫線モード & 罫線保護編集
- **モード切替**: `F5` または `:keisen`
- **罫線を描く**: `Ctrl + 矢印キー` または `Alt + 矢印キー`
  - 四角形を描いた際に角がほつれず、幾何学的に判定された綺麗な角（`┌`, `┐`, `└`, `┘`）へと自動結合されます。
  - 最下行より下へ縦線を引く場合は自動的に行拡張（改行・空白補填）されます。
- **罫線を消す**: `Shift + 矢印キー`（周囲の接続関係を自動再計算して修復）
- **通常カーソル移動**: 罫線モード有効時でも、修飾キーなしの矢印キーや `h`/`j`/`k`/`l` は通常移動となり、罫線は引かれません。
- **罫線保護入力 & 削除**:
  - 罫線枠（`│ ... │`）内での文字入力時、右側の空白文字が自動削減され外枠の位置を完全にキープ（半角入力時は半角1文字、全角入力時は半角2文字分または全角1文字分を自動消費）。
  - 挿入モードでの `Backspace` / `Delete` だけでなく、ノーマルモードでの vi `x` / `X` キーでの文字削除時にも、右枠線直前に半角スペースが自動補填され外枠の崩れを防止。
- **枠内テキスト整列**: `:align left`, `:align center`, `:align right`

### (3) 画面分割・マルチビュー (Split / Vsplit)
- **水平分割**: `Ctrl-w s` または `:split` (`:sp`)
- **垂直分割**: `Ctrl-w v` または `:vsplit` (`:vs`)
- **Vim互換の階層分割ツリー**: ウィンドウレイアウトを二分木（Window Tree）で管理。`:split` で上下分割した後に下窓で `:vsplit` を実行しても、全体が縦3列にならず下窓のみが左右分割される自然なネスト分割を実現。
- **独立したスクロール & カーソル**: 各分割ウィンドウは独立したスクロール行・スクロール列、カーソル座標を個別に保持。スクロールが勝手に同期することなく、同一バッファの異なる箇所を自由に並行編集可能。
- **幾何学的フォーカス移動**: `Ctrl-w h/j/k/l`（左・下・上・右）または `Ctrl-w w`（巡回移動）。画面上の実際の配置座標に基づき直感的に移動。
- **アクティブ閉鎖**: `Ctrl-w c` または `:close` (`:q`)
- **単一ウィンドウ化**: `Ctrl-w o` または `:only`

### (4) アウトライン解析ペイン (`F2`, `F8`, `:outline`)
- `F2`、`F8`、または `:outline` で画面左側にシンボルツリーペインを表示／非表示トグル。
- 開いた直後に自動的にアウトライン選択フォーカスへ移行し、`j` / `k` で項目を選んで `Enter` で該当行へ即時ジャンプ。
- `Tab` または `Esc` を押すことで、アウトラインを表示したままエディタ本文へ瞬時にフォーカスを戻せます。
- Markdownの見出し（`#`）、Rust（`fn`, `struct`, `impl` 等）、C/C++、Pythonの定義を自動抽出。

### (5) 検索・ハイライト & ローマ字日本語検索 (Migemo / `g/`)
- **ローマ字日本語検索 (Migemo)**:
  - ノーマルモードで `g/` を打鍵（または `:migemo <query>` を実行）すると、IMEオフのままローマ字（例: `g/kensaku`）で日本語（「検索」「けんさく」）をダイレクト検索。
  - **記号・約物の完全ヒット**: `g/kakko` で漢字「括弧」だけでなく各種括弧記号（`「」`, `（）`, `【】`, `()` 等）に、`g/yajirushi` で漢字「矢印」や記号（`→`, `←`, `↑`, `↓`, `=>` 等）に一括マッチ。丸（`maru`）や点（`ten`）、波線（`nami`）等も網羅。
  - **クリーンな独自MIT内蔵辞書**: 外部ファイルなしで即座に基本語彙・約物記号が利用可能（GPL完全排除・100%安全な独自データ）。
  - **本格利用時の外部SKK辞書拡張**: `%USERPROFILE%\.vivivi\SKK-JISYO.L` に公式SKK辞書を配置すれば、10万語規模の本格辞書へ自動拡張されます。
  - マッチした行へ画面が自動スクロール追従。
- **通常検索**: `/pattern`（順方向）、`?pattern`（逆方向）、`*`/`#`（カーソル下単語の完全一致検索）。
- **正確なカーソル着地**: 一致したキーワードの先頭文字に正確にカーソルが移動します。
- **検索ハイライト (`hlsearch`)**: 画面内の一致箇所がオレンジ背景・黒太字でリアルタイムにハイライト表示されます。
- **ハイライト消去**: `:noh`, `:nohl`, `:nohlsearch` の実行、またはノーマルモードで `Esc` を2回連打（ダブルEsc）すると一時的にハイライトを消去できます。
- `Enter` で確定後、`n` で次の一致、`N` で前の一致へジャンプ。

### (6) クリップボード履歴ダイアログ (`F6`, `:cbhist`)
- `F6` または `:cbhist` で過去のヤンク・コピー履歴一覧をポップアップ表示。
- `j` / `k` で履歴アイテムを選択し、`Enter` で現在カーソル位置へ即座にペースト。

### (7) 文字種一括変換 (`conv`)
- 全角英数 $\to$ 半角: `:hankaku`（選択範囲またはバッファ全体）
- 半角英数 $\to$ 全角: `:zenkaku`
- ひらがな $\to$ カタカナ: `:katakana`
- カタカナ $\to$ ひらがな: `:hiragana`
- 半角カナ $\to$ 全角カタカナ: `:zenkata`
- 全角カタカナ $\to$ 半角カナ: `:hankata`
- 大文字 / 小文字変換: `:toupper` / `:tolower`

### (8) BOX選択数値集計 (`calc`)
- `Ctrl-v` で数値列を矩形選択し、`:calc` または `:sum` / `:total` を実行。
- 選択範囲内の数値を集計し、件数・合計・平均・標準偏差をステータス行に表示＆クリップボードへコピー。

### (9) ViVi独自vi拡張コマンド & ナビゲーション
- **fFtT 全角文字自動マッチ**: `f`, `F`, `t`, `T` で半角英数記号を入力した際、対応する全角文字（数字、括弧 `（）`、記号 `：！`）へも自動的にマッチしてジャンプ（`;` で順方向、`,` で逆方向繰り返し）。
- **カーソル単語前後検索 & 一致検索**:
  - `*` / `#`: カーソル位置の単語を完全一致（`\bword\b`）で前方／後方検索。
  - `g*` / `g#`: 単語境界なし（部分一致）で前方／後方検索。
  - `g<` / `g=`: カーソル下の単語を前方一致（プレフィックス）／後方一致（サフィックス）で前方検索。
- **数値・英字増減 & 真偽値トグル**:
  - `#+` / `##`: 数値の加算（+1）、英字の順送り（`a` $\to$ `b`）。
  - `#-`: 数値の減算（-1）、英字の逆送り（`b` $\to$ `a`）。
  - `#!`: 真偽値の反転トグル（`true` ⇄ `false`, `yes` ⇄ `no`, `on` ⇄ `off`）。
- **直前編集位置復帰 & 前行文字列複製**:
  - `@`: 直前に文字の入力・削除・置換を行った座標へ即座に復帰ジャンプ。
  - `'@` / `` `@ ``: 直前に編集した行の先頭へジャンプ。
  - `=<char>`: 直前の行の同列位置から指定文字 `<char>` までの文字列をカレント行へ複製挿入。
- **マーク機能**:
  - `ma`〜`mz`: カレントバッファ内のローカルマーク登録。
  - `mA`〜`mZ`: ファイルパスを保持する大文字の永続グローバルマーク登録。
  - `'a` / `` `a ``: マークした行・列へジャンプ。
  - `:marks`: 登録済みマーク一覧の表示。
- **タグジャンプ**:
  - `Ctrl-]` / `:tag <name>`: カーソル下の関数・構造体・変数シンボルの定義位置へジャンプ（`tags` ファイル探索および同一バッファ構文解析フォールバック）。
  - `Ctrl-t` / `Ctrl-[`: タグスタックをポップし、ジャンプ前の位置へ復帰。
  - `:tags`: タグジャンプ履歴スタックの一覧表示。

## 3. 高度編集支援 & 高速マクロ操作

### (1) テキストアライン (`:align <記号>`)
- **コマンド**: `:align =`, `:align :`, `:align ,`, `:align //` 等
- **操作**: 揃えたい複数行（またはビジュアル選択範囲）でコマンドを実行すると、指定した記号のカラム位置が垂直にピシッと揃います。

### (2) リナンバ (連番再付番 / `:renumber`)
- **コマンド**: `:renumber [start] [step]` または `:renum [start] [step]`
- **操作**: `1.`, `2)`, `(1)`, `[1]` 等の連番リストを選択して実行すると、インデントを維持したまま指定開始番号から等差増分で綺麗に再採番します（例: `:renumber 1 1`, `:renum 10 10`）。

### (3) 行頭・行末一括挿入 (`:insbeg`, `:insend`, `:begend`)
- **行頭挿入**: `:insbeg // `（インデントを保持して空行以外の行頭に一括挿入）
- **行末挿入**: `:insend ;`（行末に一括挿入）
- **両端一括挿入**: `:begend <li> </li>`（行頭と行末を同時にタグ等で囲む）

### (4) 動的単語補完 (dabbrev / `Ctrl-l`, `Ctrl-m`)
- 挿入モード中、単語の頭を数文字入力して `Ctrl-l` を押すと、バッファ内から候補を後方・前方走査して補完。
- `Ctrl-l` で次候補へ、`Ctrl-m` で前候補へ巡回。

### (5) 静的略語展開 (abbrev / `Ctrl-;`, `Alt-;`, `F4`)
- 挿入モード中、略語（例: `fn`, `struct`, `hw`, `todo`）の直後で `Ctrl-;`（または `Alt-;` / `F4`）を押すとスニペットへ瞬時に展開。
- **略語の動的登録**: `:abbrev <key> <value>`（例: `:abbrev hw Hello World!`）

### (6) ダイナミックマクロ (増井式リピート / `Alt-m`, `Ctrl-Alt-m`)
- 事前の記録開始操作が一切不要なインテリジェントマクロ。
- 同じ編集や入力を2回繰り返した直後に `Alt-m` を押すと、直前の反復パターン（XX）を推測して自動実行。
- 連続して `Alt-m` を押すことで、何回でも続けて反復適用可能。

### (7) 字句編集予測 (LexEdit / `Ctrl-j`)
- 単語の編集や置換を行うと履歴が蓄積されます。
- 類似の単語上で `Ctrl-j` を押すと、編集の意図を推測して次の置換を即座に適用（例: `old_user` $\to$ `new_user` の後、`old_role` 上で `Ctrl-j` を押すと `new_role` へ置換）。

### (8) Zen-Coding (Emmet) 展開 (`Ctrl-,`, `Alt-,`, `:zen`)
- 挿入モード中、HTML短縮記法（例: `ul#nav>li*3>a` や `div.container`）の直後で `Ctrl-,` または `Alt-,` を押すと、正規の入れ子HTMLタグ構造へ一括展開。

### (9) キーボードマクロ記録・再生 (`Ctrl-Alt-r`, `Ctrl-Alt-p`, `F9`, `F10`)
- **ワンタッチ記録**: `F9` または `Ctrl-Alt-r` で記録開始／終了をトグル。
- **ワンタッチ再生**: `F10` または `Ctrl-Alt-p` で直前のキー操作列を一括高速再生。
- Vi標準の `qa` ... `q` および `@a`, `@@` にも完全対応。

### (10) 式置換 (`:s/pattern/expression/e`, `:%s/pattern/expression/e`)
- **コマンド**: `:s/pattern/expression/e` または `:%s/pattern/expression/e`
- **概要**: 置換後文字列を算術式・スクリプト式として動的評価し、計算結果で置換します。
- **使用例**:
  - **価格の消費税計算（10%加算）**:
    `:%s/price: (\d+)/"price: " + int($1 * 1.1)/e`
  - **連番リナンバ**:
    `:%s/item/"item_" + $i/e` （`item_1`, `item_2`, ... へ置換）
  - **行番号プレフィックス付与**:
    `:%s/^/"Line " + $line + ": "/e`

## 6. ツール機能・ファイル管理操作ガイド（ViVi 3 / ViVi 4準拠）

### (1) 永続Undo (Persistent Undo)
- **自動動作**: ファイル保存（`:w`）時にアンドゥ履歴が `.<ファイル名>.undofile` に自動保存され、次回ファイルを開いた際に自動復元されます。エディタを閉じても編集履歴を巻き戻せます。
- **手動コマンド**:
  - `:undofile save [パス]`: 現在のUndo履歴を手動保存。
  - `:undofile load [パス]`: 指定ファイルからUndo履歴を手動読み込み。

### (2) 世代バックアップ & 簡易blame (DiffLog)
- **自動動作**: ファイルを上書き保存するたびに、前世代との差分（Unified Diff）とUNIXタイムスタンプが `.<ファイル名>.difflog` に自動追記されます。
- **世代一覧**: `:difflog` で過去の全保存履歴（世代番号・日時・変更行数）を確認できます。
- **過去世代の復元**: `:difflog restore <世代番号>` で、指定した過去世代の状態にバッファを完全に復元できます。
- **簡易blame**: `:blame` で、各行がどの世代（保存日時）で編集・追加されたかを特定・表示します。

### (3) 新規ファイル・テンプレート自動展開
- 存在しない新規ファイルを開いた際、同一ディレクトリまたは親ディレクトリにある `.template.<拡張子>`（例: `.template.rs`）を自動探索します。
- テンプレート内の `%FileName%`, `%FileBase%`, `%Ext%`, `%Date%`, `%Time%`, `%UserName%`, `%Cursor%` などのマクロ変数が自動置換されてバッファに展開されます。

### (4) コード内 ToDo 抽出 (`:todo`, `:undone`)
- **コマンド**: `:todo [ディレクトリ]` または `:undone [ディレクトリ]`
- カレントバッファまたはプロジェクトディレクトリを走査し、コメント内の `TODO`, `FIXME`, `BUG`, `UNDONE`, `HACK`, `NOTE`, `XXX` を一覧抽出します。
- 該当ファイル・行番号・タグ・説明が表示され、QuickFix感覚で即座に対象箇所へジャンプできます。

### (5) コード折り畳み (Code Folding / `z`)
インデント階層に基づいてコードブロックを折り畳み・展開できます。
- **キー操作**:
  - `zc`: カーソル行のブロックを折り畳む（Close）。
  - `zo`: カーソル行の折り畳みを展開する（Open）。
  - `za`: 折り畳み／展開をトグル。
  - `zM`: バッファ全体の全ブロックを一括折り畳み。
  - `zR`: バッファ全体の全ブロックを一括展開。
  - `z<lvl>`: 指定インデント深度 `<lvl>` より深いブロックを折り畳み（例: `z2`）。
- **exコマンド**: `:fold <toggle|close|open|all|none>`

### (6) プロジェクト内高速 Grep 検索 (`:grep`)
- **コマンド**: `:grep <検索語/正規表現> [ディレクトリ]`
- プロジェクト内の全テキストファイルを高速走査します（`.git` や `target` 等の管理・ビルドディレクトリ、バイナリファイルは自動除外）。
- **結果ナビゲーション**:
  - `:cnext` または `:cn`: 次のマッチ箇所へジャンプ。
  - `:cprev` または `:cp`: 前のマッチ箇所へジャンプ。

### (7) 2ペイン ディレクトリビュー（ファイラー / `:filer`)
- **コマンド**: `:filer [パス]`
- 左右独立の2画面ファイルマネージャを表示します。
- **操作体系**:
  - `Tab`: 左右ペイン間のフォーカス切り替え。
  - `j` / `k`: カーソル移動。
  - `Enter`: ディレクトリ移動（`..` で親階層）、またはファイルをエディタで開く。
  - `Space`: 複数ファイルの選択／解除。
  - `c`: 選択したファイル・ディレクトリを反対側ペインへコピー。
  - `m`: 反対側ペインへ移動。
  - `d`: 選択したファイルの削除。

### (8) プロジェクト管理 & tags一括生成 (`:maketags`)
- **コマンド**: `:maketags [ディレクトリ]`
- プロジェクト内の全ソースファイルを再帰探索・構文解析し、ctags互換の `tags` ファイルを一括自動生成します。生成後は `Ctrl-]` によるタグジャンプが利用可能になります。

### (9) 印刷プレビュー & PDF直接出力 (`:preview`, `:pdf`)
- **印刷プレビュー**: `:preview` または `:print` で、A4用紙基準（ヘッダー・フッター・行番号付き）の印刷イメージを全画面モーダルで表示。`j`/`k` や `d`/`u` でスクロール確認し、`Esc` または `q` で終了。
- **PDF直接出力**: `:pdf [出力先パス]` で、外部ツールやライブラリを一切使わず、PDF 1.4 準拠のPDFファイルを直接生成してディスクへ保存します。
- *(※デスクトップGUI (egui) およびGUI前提機能はユーザー指示に基づきフェーズ5へ移行し、現在はTUIとコアツール機能に特化)*

## 6. 高度エディタ機能 & 堅牢化 (Phase 4.8)

### (1) マルチタブ管理 (Tab Bar UI)
複数のバッファやタスクをタブで並行管理できます。2つ以上のタブを開くと画面最上部にタブバーが自動表示されます。
- **キー操作**:
  - `gt`: 次のタブへ切り替え（末尾からは先頭へ循環）。
  - `gT`: 前のタブへ切り替え。
  - `[count]gt`: 指定番号のタブへ直接ジャンプ（例: `2gt`）。
- **exコマンド**:
  - `:tabnew [ファイル名]` / `:tabe [ファイル名]`: 新しいタブを作成。
  - `:tabclose` / `:tabc`: カレントタブを閉じる。
  - `:tabnext` / `:tabprev`: 次／前のタブへ切り替え。
  - `:tabonly` / `:tabo`: カレントタブ以外の全タブを閉じる。

### (2) 矩形選択一括編集 (Visual Block Operations)
`Ctrl-v` による矩形選択に対し、複数行にわたる列編集を一括実行できます。
- `I<text>Esc`: 選択行すべての左端にテキストを一括挿入。
- `A<text>Esc`: 選択行すべての右端にテキストを一括追加。
- `c<text>Esc`: 選択矩形領域を一括置換。
- `r<char>`: 選択矩形領域を指定文字で一括塗りつぶし。
- `d` / `x`: 選択矩形領域を一括削除し後続文字を詰める。

### (3) 設定ファイルと永続カスタマイズ (`config.toml`)
`%USERPROFILE%\.vivivi\config.toml` に設定を記述することで、起動時に自動適用されます。
- **設定項目**: `tab_stop`, `number`, `relative_number`, `wrap`, `gutter`, `hlsearch`, `clipboard`, `theme`, 不可視文字, キーマップ。
- **動的再読込**: 起動中に `:config` を実行すると即座に再読込・反映されます。
- **動的オプション設定**: `:set number` / `:se nu` / `:se nonu`（行番号）、`:set wrap` / `:se wrap` / `:se nowrap`（折り返し）、`:set relativenumber` / `:se rnu`、`:set tabstop=4`（`:se ts=4`）、`:set clipboard=unnamed` 等。末尾に `?` を付けることで現在値を確認可能（例: `:se wrap?`）。

### (4) 文字コード・改行明示変換
- `:e ++enc=<enc> [file]`: 指定文字コード（`utf-8`, `sjis`, `euc-jp`）でファイルを強制再読込。
- `:set fenc=<enc>`: ファイル保存時の文字コード（`utf-8`, `sjis`, `euc-jp`）を指定。
- `:set ff=unix` / `:set ff=dos`: 改行コード（LF / CRLF）を変換保存。

### (5) クラッシュリカバリ・スワップファイル (.swp)
- **自動保存**: 20打鍵ごと、および `Esc` でのノーマル復帰時に `.<ファイル名>.swp` へ自動保存。
- **復元プロンプト**: クラッシュ後の次回起動時に警告が表示され、`:recover` で直前の未保存状態を復元できます。
- **スワップ確認**: `:swap` でスワップファイルの詳細情報を確認できます。

### (6) システム共有クリップボード連携
- `"+y` / `"*y`: 選択範囲やヤンクを OS クリップボードへ直接コピー。
- `"+p` / `"*p`: OS クリップボードから直接貼り付け。
- `:set clipboard=unnamed`: 通常の `y` / `p` を OS クリップボードと透過同期。

### (7) 構文強調対応言語の拡充 (全18言語)
- 標準の11言語に加え、Go (`.go`), Ruby (`.rb`), TOML (`.toml`), PowerShell (`.ps1`), YAML (`.yaml`), XML (`.xml`), Windows Batch (`.bat`, `.cmd`) を追加。ステータスバーに言語バッジが自動表示されます。
