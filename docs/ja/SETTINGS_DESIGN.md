# vivivi: 設定管理＆設定画面・ダイアログ設計ハブ (SETTINGS_DESIGN.md)

> [!IMPORTANT]
> 本書は、`vivivi`（TUI / GUI 両エディション共通）における設定永続化アーキテクチャ、テーマ設計、ウィンドウ状態記憶、および設定画面UI設計を取りまとめる **統合ナビゲーション・ハブ仕様書** です。
> ViVi 3 / 4 の伝統的な2大プロパティ設計思想を継承・現代化し、役割ごとに `settings/` ディレクトリ配下の個別仕様書に分割・管理されています。

---

## 1. ViVi 3 / 4 の設計思想の継承と現代化

かつての ViVi 3 / 4 では、設定画面が **「共通プロパティ」** と **「タイプ別プロパティ (F8)」** の2大プロパティシートに分かれ、それぞれ10個前後のタブで構成される非常に強力で緻密な設定体系を備えていました。
`vivivi` では、この優れた直交設計（全体共通動作と拡張子別動作の分離）を尊重し、現代の Rust / エディタ標準として **TOML 形式 / JSON キャッシュ** へスマートに再構築・継承します。

### ViVi 3 / 4 と vivivi の設定体系対応マップ

| ViVi 3/4 の設定体系         | 当時の主なタブ・役割                                         | vivivi での現代的配置・仕様書                                |
| :-------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **共通プロパティ**          | 起動、ファイル、編集、vi、検索、書式、カーソル、カスタマイズ | [`config_spec.md`](settings/config_spec.md) (`config.toml`) |
| ↳ **起動タブ (位置・サイズ)** | 起動時のウィンドウ位置・サイズの復元、多重起動禁止           | [`window_state.md`](settings/window_state.md) (JSONキャッシュ) |
| **タイプ別プロパティ (F8)** | カラー、ビュー、入力、レイアウト、アウトライン、印刷         | [`themes_spec.md`](settings/themes_spec.md) ＆ `types/`     |
| **設定ダイアログ・UI**      | 左右2ペイン／タブ型プロパティシート、Exコマンド境界          | [`dialog_ui.md`](settings/dialog_ui.md) (egui / Ratatui)     |

## 2. 設定仕様書マップ（ハブ＆スポーク目次）

各詳細仕様は以下のドキュメントに分割・体系化されています。

| 仕様書名                                           | 役割・内容                                                   | 主な対象ファイル / 項目                              |
| :------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------- |
| **[`config_spec.md`](settings/config_spec.md)**     | エディタ基本動作・表示・キーマップの設定仕様と自動配備       | `%USERPROFILE%\.vivivi\config.toml`                  |
| **[`themes_spec.md`](settings/themes_spec.md)**     | TUI / GUI 共通テーマカラー定義、内蔵5大テーマ、ホットリロード | `%USERPROFILE%\.vivivi\themes\*.toml`                |
| **[`window_state.md`](settings/window_state.md)**   | GUI ウィンドウ位置・サイズ・最大化の記憶と画面外脱出ガード   | `%USERPROFILE%\.vivivi\cache\window_state.json`      |
| **[`dialog_ui.md`](settings/dialog_ui.md)**         | egui / Ratatui 設定画面ワイヤーフレーム、Exコマンド境界ルール | 設定ダイアログ、`:set`, `:colorscheme`, `:mkvivivirc` |

## 3. 全体ディレクトリ構成 (`%USERPROFILE%\.vivivi\`)

```
%USERPROFILE%\.vivivi\
├── config.toml                # エディタ基本設定・キーマップ・動作オプション (config_spec.md)
├── themes\                    # カラーテーマ専用ディレクトリ (themes_spec.md)
│   ├── tokyo-night.toml       # デフォルトダークテーマ (Tokyo Night)
│   ├── openvivi.toml          # OpenViVi 復刻テーマ (Qt版の洗練されたダーク)
│   ├── vivi-classic.toml      # ViVi 3/4 伝統のクラシック配色 (白背景/灰背景)
│   ├── vivivi-dark.toml       # vivivi 標準モダンダークテーマ
│   └── vivivi-light.toml      # vivivi 標準モダンライトテーマ
├── types\                     # (将来) タイプ別設定 (CPP, Rust, Markdown等)
│   ├── rust.toml
│   └── markdown.toml
└── cache\                     # 履歴・スワップ・更新キャッシュ (非設定情報)
    ├── window_state.json      # GUIウィンドウ位置・サイズ・最大化状態 (window_state.md)
    ├── recent.json            # 最近使ったファイル履歴
    ├── bookmarks.json         # グローバルマーク
    └── update_check.json      # 自動更新チェックキャッシュ
```

## 4. ViVi 3 / 4 設定タブの網羅分析と vivivi への継承方針

### 4.1 共通プロパティの継承
全ファイル共通の動作。`config.toml` および `cache/` で管理します。

| 当時タブ名     | 当時の主要設定項目                                           | vivivi での対応方針                                          |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **起動**       | 終了時のウィンドウ位置・サイズの記憶復元、多重起動制限       | `cache/window_state.json` にて自動記憶・安全復元             |
| **ファイル**   | 文字コード/改行自動判別、保存時動作、ファイル位置への自動移動 | `[general]` にて `default_encoding`, `default_fileformat` 等 |
| **ファイル２** | 自動バックアップ、世代バックアップ、スワップ復旧             | `[tools]` にて `difflog` 世代管理、スワップ復旧               |
| **編集**       | アンドゥ回数、矩形選択動作、クリップボード連携               | `[general.clipboard]`, ViエンジンのUndoスタック              |
| **vi**         | viモード有効化、オープン時ノーマルモード開始、互換性レベル   | `vivivi-vi` エンジン標準搭載、`[keymap]`                     |
| **検索**       | インクリメンタルサーチ、大文字小文字無視 (ic/sc)、循環検索   | `[editing]` にて `ignorecase`, `smartcase`                   |
| **書式**       | 禁則処理（ぶら下げ・追い出し）、全角半角空白・不可視文字     | `[invisibles]` にて不可視文字スタイル管理                    |
| **カーソル**   | モード別カーソル形状（縦棒/ブロック/下線）、点滅             | GUI / TUI 端末カーソルエスケープシーケンス制御               |

### 4.2 タイプ別プロパティ (F8) の継承
拡張子（ドキュメントタイプ）ごとの設定。カラーテーマファイルおよび将来の `types/*.toml` で管理します。

| 当時タブ名     | 当時の主要設定項目                                           | vivivi での対応方針                                          |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **ビュー**     | 行番号、ルーラー、不可視文字個別表示、右端折り返し           | `[appearance]` (`line_number`, `wrap`, `gutter_markers`)     |
| **カラー**     | 背景色、文字色、予約語、コメント、リテラル、演算子の着色     | `themes/*.toml` による 24bit RGB 統一セマンティックパレット  |
| **入力**       | タブ幅 (ts)、インデント幅、スペース展開、オートインデント   | `[editing]` (`tab_width`, `expand_tab`)                      |
| **レイアウト** | 指定文字数/ウィンドウ幅折り返し、行間ピッチ、文字間隔        | `[appearance.gui]` (`line_height_multiplier`)                |
| **アウトライン** | 関数一覧・見出し抽出正規表現設定                             | `vivivi-modes` のアウトラインパーサー                        |
| **キーワード** | 構文強調キーワード登録（予約語リスト）                       | `types/*.toml` 構文ハイライター定義                          |

## 5. 実装計画とロードマップ

1. **ステップ 1: 外部テーマ TOML パーサー＆ローダーの実装 (`vivivi-gui::theme` / 共通化)**
   - `themes/<name>.toml` の構造体定義（serde Serialize/Deserialize）。
   - `%USERPROFILE%\.vivivi\themes\` からのファイル読み込みと動的テーマ生成。
2. **ステップ 2: 初期起動ブートストラップ処理の実装 (`vivivi-app::config`)**
   - `%USERPROFILE%\.vivivi\` および `themes/` の自動作成・内蔵5大テーマの自動書き出し。
3. **ステップ 3: GUI ウィンドウ状態の保存と復元 (`vivivi-gui::window_state`)**
   - 起動時の `window_state.json` 読込（画面外安全ガード付き）と終了時の座標・サイズ自動保存。
4. **ステップ 4: GUI メニューバーからの動的テーマ切り替え接続**
   - メニュー選択時にアクティブテーマを変更し、`Visuals` とエディタ描画色を即時再描画。
5. **ステップ 5: GUI / TUI 設定ダイアログのUI実装 (`dialog_ui.md`)**
   - ViVi 伝統の共通/タイプ別カテゴリをモダンに統合した設定ダイアログの構築。
