# vivivi: 仕様要件定義・リファレンスまとめ

## 0. バッファおよびアンドゥ・リドゥ仕様（OpenViVi準拠）
OpenViVi (`vivi/buffer/`) のアーキテクチャに準拠したテキスト編集コア仕様です。
詳細設計書: [BUFFER_AND_UNDO_SPEC.md](file:///c:/Users/632792/Documents/自作/vivivi/docs/BUFFER_AND_UNDO_SPEC.md)

### ギャップバッファ (`GapBuffer<T>`)
- **局所的 $O(1)$ 編集**: 編集カーソル位置に空き領域（Gap）を維持し、連続入力や削除を $O(1)$ で処理。
- **動的リサイズ**: ギャップ枯渇時に自動拡張（倍増）。
- **ギャップスライド**: カーソル移動時に必要な差分のみをメモリシフト。

### アンドゥマネージャ (`UndoMgr`)
- **連続タイピングの自動マージ**: 挿入モード中の連続入力を1つのアクションに統合（1回の `u` で取り消し可能）。
- **トランザクション対応「Undoブロック」**: `dd` や `cw`、`:%s` 等の複合変更を多重ネスト対応の単一Undo単位として一括管理。
- **保存点（Save Point）追跡**: 保存時のスタック位置と現在の状態を比較し、`is_modified` を正確に自動更新。

## 1. 基本Viエンジン仕様（OpenViVi準拠）
OpenViVi (`C:\Users\632792\Documents\参考元アプリ\openViVi\vivi\vivi64\ViEngine.cpp`) に基づく基本仕様：

### モード体系
- **Normal（コマンド）モード**: viの基本移動・操作コマンド。
- **Insert（挿入）モード**: 通常の文字入力。`Escape` でNormalモードへ復帰。
- **Replace（上書き）モード**: 文字の上書き入力。
- **Visual（選択）モード**: 文字単位選択。
- **Visual Line（行選択）モード**: `V` で開始。行単位選択。
- **Visual Block（矩形選択）モード**: `Ctrl-V` で開始。矩形範囲の選択・切り取り・貼り付け・一括挿入。
- **CommandLine（exコマンド）モード**: `:` で開始。ファイル保存、終了、正規表現置換 (`:s`, `:%s`)。

### Undo / Redo
- viの `u` でUndo、`Ctrl-r` でRedo。
- トランザクション対応のUndoブロック（一括変更を1つのUndoステップとしてまとめる）。

## 2. インラインCSV/TSVモード仕様（ViVi 4ヘルプより）
- **概要**:
  - CSV (カンマ区切り) または TSV (タブ区切り) のプレーンテキストを、各列（カラム）の最大文字幅に合わせてインラインで自動整列して表示・編集する機能。
- **表示仕様**:
  - セル文字列の囲み記号（ダブルクォート `"` または シングルクォート `'`）は表示上は隠し、データ本体を見やすく表示する。
  - **カーソル行の表示**: カーソルが存在する行は編集作業のため、クォートを含めた生のソース文字列を表示する。
  - **ヘッダ行認識**: オプションにより、指定文字（例: `#`）で始まる行をヘッダ行と認識し、独立した強調表示・区切りを行う。
  - **複数表サポート**: 複数のCSVヘッダ行を設けることで、1つのドキュメント内に独立したセル幅を持つ複数の表を混在可能。
- **編集仕様**:
  - CSVモードのまま通常通り文字挿入・削除、Viコマンド（`dd`, `p` 等による行入れ替えなど）が可能。

## 3. 罫線モード仕様（OpenViVi / ViVi 4ヘルプより）
- **概要**:
  - テキスト上にUnicode罫線文字（U+2500〜U+254B）を用いて表や枠線を直感的に描画・編集する機能。
- **操作仕様**:
  - **モード切替**: `Shift-F5` またはツールバーアイコン。
  - **罫線を引く**: 罫線モード中に `Ctrl + 矢印キー` (↑, ↓, ←, →)。
  - **罫線を消去する**: 罫線モード中に `Shift + 矢印キー`。
  - **罫線種別**: 細い罫線（Thin）、太い罫線（Thick）。
  - **文字揃え**: 罫線枠内での左揃え・中央揃え・右揃え。
- **自動結合アルゴリズム（OpenViVi `keisen.cpp` 準拠）**:
  - 各罫線文字を上下左右のビットマスク（`KT_UP_MASK`, `KT_DOWN_MASK`, `KT_LEFT_MASK`, `KT_RIGHT_MASK`）で管理。
  - 新たに罫線を引く際、隣接するマス（上・下・左・右）の罫線状態を参照し、交差する適切なUnicode文字（`┼`, `├`, `┬`, `┴`, `┤` など）へ自動変換して接続する。
