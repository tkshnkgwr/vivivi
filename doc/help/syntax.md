# 構文強調・シンタックスハイライト (Syntax Highlighting)

`vivivi` は、プログラミング言語やマークアップ言語の構文（キーワード、型、文字列、数値、コメント等）を自動的に解析し、TUI画面上で視認性高く色分け表示（シンタックスハイライト）する強力な機能を備えています。

---

## 🚀 主な特徴

1. **拡張子による自動言語判別**: ファイルを開いた際、ファイルパスの拡張子から最適な言語ハイライターを自動適用します。
2. **ステータスバー常時表示**: 現在バッファで有効になっている言語名が、ステータスバー右端にバッジ（例: `[Rust]`, `[SQL]`, `[Java]`）として表示されます。
3. **主要18言語を標準サポート**: システム開発・Web開発・スクリプト・データベース・構成管理・Windows環境で広く使われる18言語に対応しています。
4. **大文字・小文字不問の構文解析**: SQL、PL/SQL、PowerShell、バッチファイルなど、キーワードが大文字・小文字・混在で記述される言語でも正確に識別します。
5. **タグ名と属性名のハイライト分離**: HTMLおよびXMLにおいて、タグ名（キーワード色）と属性名（型色）を分離することで、マークアップ構造を直感的に視認できます。
6. **複数行・行内ブロックコメント対応**: `/* ... */`、`<!-- ... -->`、`<# ... #>` などのブロックコメントを正確にトークナイズします。

## 📋 対応言語と拡張子一覧

| 言語                    | 識別子       | 対象拡張子                                   | 主な構文ハイライト機能                                                |
| :---------------------- | :----------- | :------------------------------------------- | :-------------------------------------------------------------------- |
| Rust                    | `rust`       | `.rs`                                        | 予約語、プリミティブ型、`//` および `/* */` コメント、数値、文字列    |
| C / C++                 | `c`          | `.c`, `.h`, `.cpp`, `.hpp`, `.cc`, `.cxx`    | 制御構文、組込型、ポインタ記号、`//` および `/* */` コメント          |
| Python                  | `python`     | `.py`                                        | Pythonキーワード、組込型、`#` コメント、シングル/ダブルクォート文字列 |
| JavaScript / TypeScript | `js`         | `.js`, `.jsx`, `.ts`, `.tsx`, `.mjs`, `.cjs` | ES/TypeScript予約語、型定義、アロー関数、`//`、`/* */`                |
| JSON                    | `json`       | `.json`                                      | キー文字列、値文字列、数値、真偽値（true/false）、null                |
| Markdown                | `markdown`   | `.md`, `.markdown`                           | 見出し（`#`）、箇条書きリスト、コードブロック記法、リンク記法         |
| SQL                     | `sql`        | `.sql`                                       | ANSI/標準SQLキーワード（大文字小文字不問）、データ型、`--`、`/* */`   |
| PL/SQL                  | `plsql`      | `.pls`, `.plb`, `.pks`, `.pkb`               | Oracle PL/SQL拡張予約語、パッケージ/プロシージャ構文、`--`、`/* */`   |
| Java                    | `java`       | `.java`                                      | Java予約語、基本型/クラス型、`//`、`/* */` コメント、アノテーション   |
| HTML                    | `html`       | `.html`, `.htm`                              | タグ名（キーワード色）、属性名（型色）、`<!-- ... -->` コメント       |
| Bash / Shell Script     | `bash`       | `.sh`, `.bash`, `.zsh`                       | 制御文（if/fi, case等）、環境変数・組込型、`#` コメント               |
| Go                      | `go`         | `.go`                                        | 予約語（func/package等）、構造体/インターフェース、型、生文字列、注釈 |
| Ruby                    | `ruby`       | `.rb`                                        | 予約語（def/class等）、シンボル（`:sym`）、`#` コメント、文字列       |
| TOML                    | `toml`       | `.toml`                                      | テーブルヘッダー（`[...]`）、キー名、数値、真偽値、日付、コメント     |
| PowerShell              | `powershell` | `.ps1`, `.psm1`, `.psd1`                     | コマンドレット、制御構文、変数（`$var`）、`#` / `<# #>` コメント      |
| YAML                    | `yaml`       | `.yaml`, `.yml`                              | キー名、リストハイフン、スカラー値、アンカー/エイリアス、コメント     |
| XML                     | `xml`        | `.xml`                                       | XMLタグ名、属性名、属性値、`<?xml?>`、CDATA、`<!-- ... -->`           |
| Windows Batch (bat/cmd) | `batch`      | `.bat`, `.cmd`                               | バッチコマンド、環境変数（`%VAR%`）、ラベル（`:label`）、`rem`/`::`   |

## 🎨 強調表示されるトークン要素

| トークン種別     | 役割・対象例                                               | TUI標準カラー           |
| :--------------- | :--------------------------------------------------------- | :---------------------- |
| **キーワード**   | `fn`, `let`, `SELECT`, `class`, `if`, `function`, タグ名等 | 黄色 (Yellow)           |
| **型・クラス**   | `usize`, `String`, `VARCHAR2`, `int`, HTML属性名等         | シアン (Cyan)           |
| **文字列**       | `"..."`, `'...'`, テンプレート文字列                       | 緑色 (Green)            |
| **数値**         | `123`, `0xFF`, `3.14` 等の数値リテラル                     | マゼンタ (Magenta)      |
| **コメント**     | `//`, `#`, `--`, `/* ... */`, `<!-- ... -->` 等の注釈      | 灰色 (Dark Gray)        |
| **記号・演算子** | `( )`, `{ }`, `[ ]`, `;`, `+`, `-`, `=`, `>` 等            | 明るい灰色 (White/Gray) |
| **テキスト**     | 一般テキスト、未定義識別子                                 | デフォルト文字色        |

## 💡 便利な連携機能

- **アウトライン解析 (`F2`)**:
  Markdown見出しツリーだけでなく、Rust / C / C++ / Java / Python / JS 等の関数定義やクラス構造も自動解析され、`F2` キーでサイドペインにアウトラインツリーを表示できます。
- **ヘルプ閲覧**:
  いつでも `:help syntax` または `:h syntax` を実行することで、本ヘルプを直接バッファ内で参照できます。
