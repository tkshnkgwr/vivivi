# アウトライン解析 & サイドペインツリー (Outline)

Markdownの見出し階層（`#`, `##`, `###`）や、プログラミング言語（Rust, Python, C++等）の関数・構造体・クラスを自動抽出し、左側サイドペインにアウトラインツリーとして一覧表示する機能です。

---

## 🚀 使い方

- **ショートカット**: `F2`
- **exコマンド**: `:outline`

左側にアウトラインサイドペインが表示／非表示トグルされます。

---

## ⌨️ アウトラインペイン内の操作

| キー         | 動作                                               |
| :----------- | :------------------------------------------------- |
| `j` / `↓`    | 次の見出し／シンボル項目を選択                     |
| `k` / `↑`    | 前の見出し／シンボル項目を選択                     |
| `Enter`      | 選択した見出し・行へエディタ本文を瞬時ジャンプ     |
| `F2` / `Esc` | アウトラインペインを閉じる                         |

---

## 💡 対応フォーマット
- **Markdown**: `# 見出し1`, `## 見出し2` などの階層インデントツリー
- **Rust**: `fn function_name`, `struct StructName`, `enum EnumName`, `impl Type`
- **Python**: `def func()`, `class ClassName`
- **その他言語**: 順次拡張中
