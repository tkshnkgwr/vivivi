# vivivi ヘルプシステム (Help System)

`vivivi`（ヴィヴィヴィ）は、伝説的な国産高機能テキストエディタ **ViVi**（ViVi 3 / ViVi 4 / OpenViVi）の強力な編集支援機能と、モダンな **Vim / Neovim** の軽快な操作性を Rust で融合・現代に再構築した次世代テキストエディタです。

## ⚡ クイックリファレンス (Quick Reference)

### ファンクションキー
- **`F1`**: ヘルプを開く（本ファイル）
- **`F2`**: アウトラインツリーの表示／非表示トグル
- **`F5`**: 罫線モード（描画・保護編集）のトグル
- **`F6`**: クリップボード履歴ウィンドウの表示／非表示トグル
- **`F7`**: 最近使ったファイル & お気に入りモーダルの表示トグル

### exコマンド一覧（抜粋）
- `:help [topic]` / `:h [topic]`: ヘルプを開く（トピック名指定可）
- `:w [file]`: バッファを保存
- `:q` / `:q!`: 終了 / 強制終了
- `:wq`: 保存して終了
- `:recent` / `:mru`: 最近使ったファイル＆お気に入り一覧を開く
- `:fav` / `:favorite`: 現在のファイルをお気に入り登録／解除
- `:set list` / `:set nolist`: 不可視文字（全角スペース□/タブ/改行$）表示切替
- `:set gutter` / `:set nogutter`: 変更行ガター強調（黄:未保存, 緑:保存済）切替
- `:todo`: バッファ内 ToDo/FIXME を抽出して一覧プレビュー
- `:diff`: 保存前ファイルとの差分をプレビュー表示
- `:split` / `:vsplit`: 水平分割 / 垂直分割
- `:calc` / `:sum` / `:total`: BOX選択範囲の数値を集計
- `:cbhist` / `:history`: クリップボード履歴を表示
- `:csv` / `:tsv`: インラインCSV / TSV整列モード
- `:keisen`: 罫線モードのトグル
- `:zenkaku` / `:hankaku`: 全角半角一括変換
- `:help syntax`: シンタックスハイライト（構文強調）の対応言語・拡張子一覧を表示
- `:help visual`: 視覚・編集支援機能の詳細ヘルプを表示
