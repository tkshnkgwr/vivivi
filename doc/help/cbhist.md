# クリップボード履歴 (Clipboard History / cbHist)

過去にヤンク（コピー）または削除（カット）したテキストの履歴を自動的に蓄積し、中央のポップアップウィンドウで一覧プレビューしながら選択してペーストできる機能です。

---

## 🚀 使い方

1. **ノーマルモード** で **`F6`** キーを押すか、exコマンドを実行します：
   - `:cbhist`、`:history`、または `:clipboard`
2. 画面中央に「クリップボード履歴 (cbHist)」ウィンドウがポップアップ表示されます。
3. リストから貼り付けたい項目を選択します：
   - `j` または `↓`: 下の項目へ移動
   - `k` または `↑`: 上の項目へ移動
4. **`Enter`** を押すと、選択中のテキストが現在のカーソル位置に即座にペーストされ、ポップアップが閉じます。
5. キャンセルして閉じる場合は **`Esc`** または再度 **`F6`** を押します。

---

## ⌨️ 操作キー一覧

| キー         | 動作                                               |
| :----------- | :------------------------------------------------- |
| `F6`         | クリップボード履歴ウィンドウの表示／非表示トグル   |
| `j` / `↓`    | 次の履歴項目を選択                                 |
| `k` / `↑`    | 前の履歴項目を選択                                 |
| `Enter`      | 選択した項目をカーソル位置にペーストしてウィンドウを閉じる |
| `Esc`        | 何も貼り付けずにウィンドウを閉じる                 |

---

## 💡 仕様
- **最大保持件数**: 最新50件まで自動保持されます。
- **連続重複排除**: 直前にコピーした内容と全く同じテキストは、重複して履歴に追加されません。
- **文字単位・行単位・矩形対応**: 通常のコピーだけでなく、行削除（`dd`）や矩形ヤンク（`y`）も適切に保持されます。
