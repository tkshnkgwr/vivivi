# マルチタブ管理 (Multi-Tab Management)

`vivivi` では、複数のバッファや編集対象を画面最上部の **タブバー (Tab Bar)** によって独立したタブページとして管理できます。

---

## 📑 概要

- **独立した画面分割レイアウト**: 各タブページは、それぞれ独立したウィンドウ分割構造（`:split`, `:vsplit`）とカレントバッファ、カーソル位置を保持します。
- **自動タブバー表示**: 2つ以上のタブが開かれると、画面最上段（タイトルバーの直下）にタブバーが自動描画されます。
- **アクティブ表示**: 現在アクティブなタブはハイライト色とインデックス番号（例: ` 1: main.rs `）で強調表示され、未保存の変更がある場合はバッファ名に `[+]` が付与されます。

---

## ⌨️ キー操作

ノーマルモードにおいて、Vim / Gvim 互換の以下のキーシーケンスでタブを高速に切り替えることができます。

| キー操作         | 動作説明                                                         |
| :--------------- | :--------------------------------------------------------------- |
| `gt`             | 次のタブへ移動します（最後のタブの場合は先頭タブへ循環）。       |
| `gT`             | 前のタブへ移動します（先頭タブの場合は末尾タブへ循環）。         |
| `[count]gt`      | 指定された 1-based インデックスのタブへ直接ジャンプします（例: `2gt` で 2 番目のタブへ移動）。 |

---

## 🛠️ exコマンド

コマンドラインから以下の ex コマンドを利用してタブの生成、移動、破棄が行えます。

| コマンド                     | 動作説明                                                         |
| :--------------------------- | :--------------------------------------------------------------- |
| `:tabnew [file]`             | 新しい空のタブを作成します。ファイル名を指定した場合はそのファイルを開きます。 |
| `:tabe [file]` / `:tabedit`  | `:tabnew` のエイリアス。指定したファイルを新タブで開きます。     |
| `:tabclose` / `:tabc`        | 現在アクティブなタブを閉じます。未保存の変更がある場合は警告されます。 |
| `:tabnext` / `:tabn`         | 次のタブへ切り替えます。                                         |
| `:tabprev` / `:tabp`         | 前のタブへ切り替えます。                                         |
| `:tabonly` / `:tabo`         | 現在アクティブなタブ以外のすべてのタブを閉じます。               |

---

## 💡 使用例

1. **複数ファイルの並行編集**:
   - `:tabnew src/main.rs` で別タブを開き、元のタブの画面分割レイアウトを崩さずに別の作業に着手できます。
2. **タブ間の高速往復**:
   - `gt` や `gT` を連打して直感的にタブを切り替えられます。
