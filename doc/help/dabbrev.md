# 動的補完 (Dynamic Abbreviation / dabbrev)

バッファ内（編集中ドキュメント）に既に登場している単語を自動検索し、現在入力中のプレフィックス（単語の先頭部分）に一致する単語をサイクリックに展開・補完する高速入力支援機能です。

---

## 🚀 使い方

1. **挿入モード** 中に、補完したい単語の頭（数文字）を入力します。
   - 例: `buf` と入力
2. **`Ctrl-l`** を押すと、カーソルから上方向（直前）、続いて下方向（後方）へバッファ内をスキャンし、一致する候補で残りの文字列を自動補完します。
   - 例: `buffer` が補完され、カーソルが単語末尾に進みます。
3. 続けて **`Ctrl-l`** を押すと、次の候補（例: `buffer_size` → `buffered`）へ次々に切り替わります（サイクリック巡回）。
4. 行き過ぎた場合は **`Ctrl-m`** を押すことで、1つ前の補完候補に戻すことができます。

---

## ⌨️ キーバインドまとめ

| キー     | モード   | 動作                                               |
| :------- | :------- | :------------------------------------------------- |
| `Ctrl-l` | 挿入     | 次の動的補完候補を展開・サイクリック巡回           |
| `Ctrl-m` | 挿入     | 前の動的補完候補に戻る                             |
| その他   | 挿入     | 別の文字を入力するかEscを押すと補完セッション終了  |

---

## 💡 特徴
- **距離優先**: カーソル位置から物理的に近い単語が優先的に候補に上がります。
- **重複排除**: 同一単語は自動的にまとめられ、重複して現れません。
- **マルチバイト対応**: 英数字・アンダースコア（`[A-Za-z0-9_]`）の識別子に対応しています。
