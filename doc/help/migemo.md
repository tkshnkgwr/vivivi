# ローマ字日本語検索 (Migemo Search / g/)

日本語入力（IME）をONに切り替えることなく、キーボードのローマ字（ASCII英字）入力のままで、文書内の日本語（漢字・ひらがな・カタカナ）を直接インクリメンタル検索できる機能です。

---

## 🚀 使い方

1. **ノーマルモード** で **`g/`** と入力します。
   - 最下行に `g/` のプロンプトが表示され、Migemo検索入力モードになります。
2. 検索したい言葉をローマ字で入力します：
   - 例: `g/nihon` と入力すると、「日本」「にほん」「ニホン」等にマッチする正規表現パターンが内部生成されます。
   - 例: `g/kensaku` と入力すると、「検索」「けんさく」「ケンサク」等にマッチします。
   - 例: `g/kakko` と入力すると、「括弧」だけでなく各種括弧記号「（）」「「」」「【】」「()」「[]」等にもマッチします。
   - 例: `g/yajirushi` と入力すると、「矢印」だけでなく記号「→」「←」「↑」「↓」「=>」等にもマッチします。
3. **`Enter`** を押すと検索が実行され、最初にマッチした箇所へカーソルがジャンプします。
4. 通常のvi検索と同様に：
   - **`n`**: 次の一致箇所へ順方向ジャンプ
   - **`N`**: 前の一致箇所へ逆方向ジャンプ

---

## ⌨️ 操作キー・コマンド一覧

| キー / コマンド   | 動作                                               |
| :---------------- | :------------------------------------------------- |
| `g/`              | Migemo ローマ字日本語検索プロンプトを開始          |
| `:migemo <query>` | exコマンドから直接Migemo検索を実行                 |
| `Enter`           | 検索を実行し、最初の一致箇所へジャンプ（画面追従） |
| `Esc`             | 検索プロンプトをキャンセル                         |
| `n`               | 次の一致箇所へジャンプ                             |
| `N`               | 前の一致箇所へジャンプ                             |

## 💡 特徴

- **クリーンな内蔵辞書 (Built-in Clean MIT Dictionary)**:
  - 括弧類（`kakko`）、矢印（`yajirushi`）、丸（`maru`）、点（`ten`）などの各種約物・記号や、エディタ操作・日常頻出語彙を網羅した独自作成のMIT適合辞書がバイナリ内に組み込まれています。
  - 外部辞書ファイルのダウンロードや設定を一切行うことなく、導入直後から「括弧」「矢印」「検索」「設定」「日本語」「機能」などに即座にヒットします。
- **外部SKK辞書の拡張読込（本格利用時）**:
  - `%USERPROFILE%\.vivivi\SKK-JISYO.L`（またはカレントディレクトリ）に本格SKK辞書を配置することで、数十万語の語彙へと自動拡張されます（UTF-8, EUC-JP, Shift_JIS自動判別）。
- **促音・拗音・撥音対応**:
  - `tt` や `kk` による促音（っ）、`kya`, `shu`, `cha` などの拗音、`nn` による撥音（ん）に完全対応しています。
- **画面自動スクロール追従**:
  - ヒットした行が画面外にある場合でも、該当行が視界に入るよう画面が自動スクロール追従します。

## 📚 辞書について（内部辞書と外部SKK辞書）

### 1. 内部辞書の役割と収録範囲
バイナリに最初から組み込まれている内部辞書は、**ライセンス安全（MIT）かつ超軽量（約128語・主要記号群）に最適化**されています。
- 括弧・約物記号（`kakko`）: `括弧`, `「` `」` `(` `)` `（` `）` `【` `】` `『` `』` `[` `]` `［` `］` `{` `}` `｛` `｝` 等
- 矢印記号（`yajirushi`）: `矢印`, `→` `←` `↑` `↓` `⇒` `⇔` `->` `=>` `<-`
- 記号類（`maru`, `ten`, `kara`, `nami`）: `○`, `●`, `◎`, `。`, `、`, `・`, `〜`, `～`
- 基本語彙・方向: 検索、置換、保存、編集、ファイル、行、列、画面、右、左、上、下 等

### 2. 本格的に利用する場合（外部SKK辞書の導入推奨）
内部辞書は基本操作や記号類に特化しているため、**小説執筆・長文ドキュメント・プログラムコメント・専門用語など、あらゆる日本語テキストを快適に横断検索するには、公式の外部SKK辞書（約10万語）の導入を推奨（本格運用時は必須）**いたします。

外部辞書を配置すると、内部辞書と自動的にマージされ、10万語規模の膨大な日本語熟語・固有名詞・人名・地名がすべてローマ字で検索できるようになります。

### 3. SKK辞書のダウンロード先サイト
公式のSKK辞書は、SKKプロジェクトによりオープンソース（GPL）として無料公開されています：

- **公式GitHubリポジトリ (辞書データ一覧)**:
  - [https://github.com/skk-dev/dict](https://github.com/skk-dev/dict)
- **公式サイト (SKK Openlab)**:
  - [https://skk-dev.github.io/dict/](https://skk-dev.github.io/dict/)
- **推奨辞書ファイル**:
  - **`SKK-JISYO.L`**（大辞書: 約10万語、最も一般的で全方位カバー）
  - **`SKK-JISYO.M`**（中辞書: 約1.7万語、軽量標準）

### 4. 外部辞書の配置手順
1. 上記サイトから `SKK-JISYO.L`（または `SKK-JISYO.M`）をダウンロードします。
2. 以下のいずれかの場所にファイルを配置します：
   - **Windows**: `%USERPROFILE%\.vivivi\SKK-JISYO.L`（または `vivivi.exe` と同じディレクトリ）
   - **Linux / macOS**: `~/.vivivi/SKK-JISYO.L`（またはカレントディレクトリ）
3. `vivivi` を起動すると自動的に検出され、バックグラウンドで瞬時にロードされます。
   ※ 辞書の文字コードは EUC-JP、UTF-8、Shift_JIS（CP932）のいずれも自動判別されます。
