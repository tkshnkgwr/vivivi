# ローマ字日本語検索 (Migemo Search / g/)

日本語入力（IME）をONに切り替えることなく、キーボードのローマ字（ASCII英字）入力のままで、文書内の日本語（漢字・ひらがな・カタカナ）を直接インクリメンタル検索できる機能です。

---

## 🚀 使い方

1. **ノーマルモード** で **`g/`** と入力します。
   - 最下行に `g/` のプロンプトが表示され、Migemo検索入力モードになります。
2. 検索したい言葉をローマ字で入力します：
   - 例: `g/nihon` と入力すると、「日本」「にほん」「ニホン」等にマッチする正規表現パターンが内部生成されます。
   - 例: `g/kensaku` と入力すると、「検索」「けんさく」「ケンサク」等にマッチします。
3. **`Enter`** を押すと検索が実行され、最初にマッチした箇所へカーソルがジャンプします。
4. 通常のvi検索と同様に：
   - **`n`**: 次の一致箇所へ順方向ジャンプ
   - **`N`**: 前の一致箇所へ逆方向ジャンプ

---

## ⌨️ 操作キー一覧

| キー         | 動作                                               |
| :----------- | :------------------------------------------------- |
| `g/`         | Migemo ローマ字日本語検索を開始                    |
| `Enter`      | 検索を実行し、最初の一致箇所へジャンプ             |
| `Esc`        | 検索をキャンセル                                   |
| `n`          | 次の一致箇所へジャンプ                             |
| `N`          | 前の一致箇所へジャンプ                             |

---

## 💡 特徴
- **促音・拗音・撥音対応**: `tt` や `kk` による促音（っ）、`kya`, `shu`, `cha` などの拗音、`nn` による撥音（ん）に完全対応しています。
- **SKK辞書連携**: ローマ字音節からひらがな・カタカナ・代表的漢字への自動展開エンジンを備えています。
