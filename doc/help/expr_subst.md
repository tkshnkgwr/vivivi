# 式置換 (Expression Substitute)

ViVi 3 / ViVi 4 に搭載されていた強力なキラー機能 **「式置換（Expression Substitute）」** の解説です。

---

## 🎯 概要

通常のエディタの置換コマンド（`:s/pattern/replacement/`）は、固定文字列または正規表現のキャプチャグループ（`$1`, `$2` 等）を展開するのみです。
`vivivi` の式置換は、末尾フラグに `e` を指定することで、置換後文字列を**計算式（算術演算・スクリプト式）として動的に評価**して置換します。

```vim
:s/pattern/expression/e
:%s/pattern/expression/e
```

---

## ⚙️ サポート演算子・構文

| 構文 / 演算子      | 説明                                                              | 例                                   |
| :----------------- | :---------------------------------------------------------------- | :----------------------------------- |
| `+`, `-`, `*`, `/` | 四則演算（浮動小数点数および整数）                                | `($1 * 1.1)`, `($1 + 10) / 2`        |
| `%`                | 剰余（モジュロ演算）                                              | `$line % 2`                          |
| `(...)`            | 演算優先順位の括弧グループ                                        | `($1 + 5) * 3`                       |
| 文字列リテラル     | `"..."` または `'...'` による固定文字列                          | `"item_" + $i`                       |
| 文字列結合         | `+` 演算子による文字列と数値の自動結合                            | `"Total: $" + ($1 * $2)`             |

---

## 🔢 組み込み変数

| 変数名           | 説明                                                                        |
| :--------------- | :-------------------------------------------------------------------------- |
| `$0`             | マッチした文字列全体                                                        |
| `$1` 〜 `$9`     | 正規表現のキャプチャグループ（数値の場合は自動的に数値として演算可能）      |
| `$i` / `$n`      | 置換がマッチするたびに `1` から自動インクリメントされる連番カウンタ（1, 2, ...）|
| `$line`          | 現在置換が行われている物理行番号（1-based）                                |

---

## 💡 実践的な使用例

### 1. 価格の消費税計算（10%加算）
文書内の価格 `price: 1000` を10%増の税込価格へ一括更新します。

```vim
:%s/price: (\d+)/"price: " + int($1 * 1.1)/e
```
- 入力: `price: 1000` $\to$ 出力: `price: 1100`

### 2. リスト項目の連番リナンバ
行頭の `item` を `item_1`, `item_2`, ... のように連番化します。

```vim
:%s/item/"item_" + $i/e
```

### 3. 行番号をプレフィックスとして挿入
全行の行頭に現在の行番号を付与します。

```vim
:%s/^/"Line " + $line + ": "/e
```

### 4. 2つの数値の掛け算（数量 × 単価）
`3 x 500 yen` のようなテキストから合計金額を計算します。

```vim
:%s/(\d+) x (\d+) yen/($1 * $2) + " yen"/e
```
- 入力: `3 x 500 yen` $\to$ 出力: `1500 yen`
