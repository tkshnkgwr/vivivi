# 画面分割・マルチビュー (Window Split)

同一バッファまたは別バッファを上下（水平）または左右（垂直）に分割して同時に閲覧・編集する機能です。

---

## 🚀 使い方

exコマンドまたはキーバインドでウィンドウを分割します：

- **`:split`** / **`:sp`** / **`Ctrl-w s`**: 画面を上下（水平）に分割
- **`:vsplit`** / **`:vs`** / **`Ctrl-w v`**: 画面を左右（垂直）に分割
- **`:close`** / **`Ctrl-w c`** / **`:q`**: 現在フォーカスのあるウィンドウを閉じる
- **`:only`** / **`Ctrl-w o`**: 現在のウィンドウ以外をすべて閉じて単一画面にする

---

## 🌲 Vim互換の階層分割ツリー (Nested Split Tree)

`vivivi` では、ウィンドウレイアウトを二分木（Window Tree）で管理しています。
これにより、Vimと全く同じ自然なネスト分割が可能です。

- **例**: `:split` で上下に画面を2分割した後、下側のウィンドウで `:vsplit` を実行すると、**上側のウィンドウは全幅をキープしたまま、下側のウィンドウのみが左右に2分割**されます。
- 画面全体が予期せず3列に変わってしまうようなことはなく、思い通りの複雑なペイン構成を構築できます。

---

## 📜 独立したスクロール & カーソル管理

- 分割された各ウィンドウは、**独立したカーソル座標およびスクロール位置（垂直・水平）**を完全に個別保持します。
- 一方のウィンドウをスクロールしても他方のウィンドウが勝手に連動スクロールすることはありません。
- 同一ファイル内の異なる関数や離れた行を見比べながらの並行参照・編集が極めて快適に行えます。

---

## ⌨️ ウィンドウフォーカス移動

`Ctrl-w` に続けて方向キー（Viモーションキー）を押すことで、フォーカスするウィンドウを切り替えます。
画面上の幾何学的配置（座標・近傍判定）に基づき、見た目の配置通りに直感的に移動できます。

| キー         | 動作                                               |
| :----------- | :------------------------------------------------- |
| `Ctrl-w w`   | 次のウィンドウへフォーカスを巡回移動               |
| `Ctrl-w h`   | 左のウィンドウへフォーカス移動                     |
| `Ctrl-w j`   | 下のウィンドウへフォーカス移動                     |
| `Ctrl-w k`   | 上のウィンドウへフォーカス移動                     |
| `Ctrl-w l`   | 右のウィンドウへフォーカス移動                     |
| `Ctrl-w c`   | カレントウィンドウを閉じる                         |
| `Ctrl-w o`   | カレントウィンドウ以外をすべて閉じる               |
