# 画面分割・マルチビュー (Window Split)

同一バッファまたは別バッファを上下（水平）または左右（垂直）に分割して同時に閲覧・編集する機能です。

---

## 🚀 使い方

exコマンドでウィンドウを分割します：

- **`:split`** または **`:sp`**: 画面を上下（水平）に分割
- **`:vsplit`** または **`:vs`**: 画面を左右（垂直）に分割
- **`:q`**: 現在フォーカスのあるウィンドウを閉じる

---

## ⌨️ ウィンドウフォーカス移動

`Ctrl-w` に続けて方向キー（Viモーションキー）を押すことで、フォーカスするウィンドウを切り替えます。

| キー         | 動作                                               |
| :----------- | :------------------------------------------------- |
| `Ctrl-w w`   | 次のウィンドウへフォーカスを巡回移動               |
| `Ctrl-w h`   | 左のウィンドウへフォーカス移動                     |
| `Ctrl-w j`   | 下のウィンドウへフォーカス移動                     |
| `Ctrl-w k`   | 上のウィンドウへフォーカス移動                     |
| `Ctrl-w l`   | 右のウィンドウへフォーカス移動                     |
