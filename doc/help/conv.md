# 文字種一括変換 (Character Conversion)

バッファ全体または選択範囲の全角・半角、ひらがな・カタカナ、大文字・小文字を一括相互変換する機能です。

---

## 🚀 使い方

exコマンドで変換を実行します：

| コマンド      | 変換内容                                           |
| :------------ | :------------------------------------------------- |
| `:zenkaku`    | 半角英数記号および半角カナを「全角」に一括変換     |
| `:hankaku`    | 全角英数記号および全角カナを「半角」に一括変換     |
| `:hiragana`   | 全角カタカナを「ひらがな」に一括変換               |
| `:katakana`   | ひらがなを「全角カタカナ」に一括変換               |
| `:toupper`    | アルファベットをすべて「大文字」に一括変換         |
| `:tolower`    | アルファベットをすべて「小文字」に一括変換         |

---

## 💡 動作仕様
- 選択範囲（Visualモード）がある場合は選択範囲内のみを変換し、ノーマルモードの場合はバッファ全体を一括変換します。
- 変換操作は `u`（Undo）で1ステップで元に戻すことができます。
