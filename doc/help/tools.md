# ツール機能・ファイル管理 (Tools & File Management)

ViVi 3 / ViVi 4 準拠の強力なツール機能およびファイル管理コマンドの解説です。

---

## 1. プロジェクト内Grep検索 (`:grep`)

プロジェクトまたは指定ディレクトリ内のファイルを高速に走査し、正規表現で一括検索します。

| コマンド                 | 機能概要                                                                |
| :----------------------- | :---------------------------------------------------------------------- |
| `:grep <pattern> [path]` | 指定パス（省略時はカレント）配下を走査し `<pattern>` を高速正規表現検索 |
| `:cnext` または `:cn`    | Grep 検索結果の次の該当箇所へジャンプ                                   |
| `:cprev` または `:cp`    | Grep 検索結果の前の該当箇所へジャンプ                                   |

※ `.git`, `target`, `node_modules` などのビルド成果物やバイナリファイルは自動的に走査対象外となります。

---

## 2. タグジャンプ & タグ一括生成 (`:tag`, `:tags`, `:maketags`)

ソースコード内のシンボル（関数・構造体・メソッド等）定義へ瞬時にジャンプします。

| コマンド / キー操作 | 機能概要                                                                   |
| :------------------ | :------------------------------------------------------------------------- |
| `:tag <name>`       | 指定シンボル名の定義箇所へタグジャンプ                                     |
| `Ctrl-]`            | カーソル位置の単語をタグ名として定義元へ即時ジャンプ                       |
| `Ctrl-t`            | 直前のタグジャンプ元位置へ復帰（ポップ）                                   |
| `:tags`             | 現在のタグスタック履歴一覧を表示                                           |
| `:maketags`         | カレント配下を走査し、シンボル定義インデックス（`tags`）ファイルを一括生成 |
| `:tags gen`         | `:maketags` と同様に `tags` ファイルを生成・更新                           |

---

## 3. 差分比較プレビュー (`:diff [path]`)

バッファの変更内容を unified diff 形式でモーダル画面にプレビュー表示します。

| コマンド       | 機能概要                                                             |
| :------------- | :------------------------------------------------------------------- |
| `:diff`        | 現在のバッファとディスク上の元ファイルとの未保存差分をプレビュー表示 |
| `:diff <path>` | 現在のバッファと指定された外部ファイルとの差分をプレビュー表示       |

※ プレビュー画面は `j` / `k` でスクロールでき、`q` または `Esc` で即座にエディタへ復帰します。

---

## 4. コード内 ToDo 抽出 (`:todo` / `:undone`)

ソースコード内のコメントから、未完了タスクや留意事項タグを自動抽出します。

| コマンド            | 機能概要                                                          |
| :------------------ | :---------------------------------------------------------------- |
| `:todo` / `:undone` | `TODO`, `FIXME`, `BUG`, `UNDONE`, `HACK`, `NOTE` を抽出しジャンプ |

---

## 5. コード折り畳み (Code Folding)

インデント階層に基づいてコードブロックを折り畳み、長大なファイルを俯瞰しやすくします。
折り畳まれた行は `+--- N lines: <text> ---` のプレースホルダーバーとして描画されます。

| キー操作 / コマンド | 機能概要                                                         |
| :------------------ | :--------------------------------------------------------------- |
| `:fold`             | 現在のバッファのインデント階層を解析し折り畳みブロックを自動検出 |
| `zc`                | カーソル行の折り畳みブロックを閉じる                             |
| `zo`                | カーソル行の折り畳みブロックを開く                               |
| `za`                | カーソル行の折り畳みブロックの開閉をトグル                       |
| `zM`                | すべての折り畳みブロックを一括で閉じる                           |
| `zR`                | すべての折り畳みブロックを一括で開く                             |
| `z<数字>`           | 指定したネスト深度レベル（例: `z1`, `z2`）以上のブロックを閉じる |

---

## 6. 2ペイン ディレクトリビュー (ファイラー / `:filer`)

左右2画面でファイルやフォルダを管理するファイラー機能を起動します。

| コマンド / キー操作   | 機能概要                                                 |
| :-------------------- | :------------------------------------------------------- |
| `:filer` / `:explore` | 左右2ペインのファイラーを起動                            |
| `Tab`                 | 左右ペインのアクティブフォーカス切り替え                 |
| `j` / `k` (↓/↑)       | カーソル移動                                             |
| `Space`               | ファイルの選択トグル（`[✓]` チェックマーク）             |
| `Enter` / `→`         | ディレクトリに入る、またはファイルを開いてエディタへ戻る |
| `Backspace` / `h`     | 1つ上の親ディレクトリへ移動                              |
| `c`                   | 選択したファイルを反対ペインへコピー                     |
| `m`                   | 選択したファイルを反対ペインへ移動                       |
| `d` / `Delete` / `x`  | 選択したファイルを削除                                   |
| `q` / `Esc`           | ファイラーを終了してエディタへ戻る                       |

---

## 7. 世代バックアップ (DiffLog / `:difflog`)

ファイル保存ごとに差分（Unified Diff）を `.difflog` ファイルに自動追記保存します。

| コマンド   | 機能概要                                               |
| :--------- | :----------------------------------------------------- |
| `:difflog` | 蓄積されている世代数および世代履歴一覧をプレビュー表示 |

---

## 8. 永続Undo (Persistent Undo / undofile)

エディタを終了しても Undo/Redo 履歴を `.<filename>.undofile` に永続化保存し、次回オープン時にシームレスに復元します。

| コマンド    | 機能概要                                                  |
| :---------- | :-------------------------------------------------------- |
| `:undofile` | 現在のバッファの Undo/Redo スタックを手動で undofile 保存 |

※ 通常の `:w` 保存時にも自動的に undofile が同期保存されます。

---

## 9. テンプレート自動読み込み (`.template.<ext>`)

新規ファイル作成時、同ディレクトリまたは `%USERPROFILE%\.vivivi\templates\`（Linux/macOS では `~/.vivivi/templates/`）配下の `.template.<ext>` を自動探索し、
マクロ変数を展開してバッファ初期テキストとして挿入します。

- `%FileName%`: ファイル名
- `%FileBase%`: 拡張子なしベース名
- `%Ext%`: 拡張子
- `%Date%`: 作成日付（YYYY-MM-DD）
- `%Time%`: 作成時刻（HH:MM:SS）
- `%UserName%`: ユーザー名
- `%Cursor%`: 展開後の初期カーソル位置

---

## 10. 印刷プレビュー & PDF出力 (`:preview`, `:pdf`)

テキストやMarkdownをページ分割（A4標準60行・ヘッダー・フッター・行番号）して画面プレビューおよびPDF直接出力を行います。

| コマンド / キー操作      | 機能概要                                                      |
| :----------------------- | :------------------------------------------------------------ |
| `:preview`, `:print`     | ページ分割された印刷プレビュー画面を全画面モーダル表示        |
| `p` (プレビュー表示中)   | 現在プレビュー中の内容を PDF ファイルとして即時出力・保存     |
| `j` / `k` (プレビュー)   | 1行スクロール                                                 |
| `d` / `u` (プレビュー)   | 10行スクロール（半画面）                                      |
| `q` / `Esc` (プレビュー) | プレビュー画面を閉じてエディタへ復帰                          |
| `:pdf [filename]`        | 外部ツール不要で A4 サイズの PDF 1.4 ファイルを直接生成・出力 |
