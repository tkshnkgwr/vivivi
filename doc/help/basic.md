# 基本操作 & モード (Basic Usage & Modes)

`vivivi` の基本的な操作方法、各種モード、主要なキーバインドです。

---

## 🧭 主なモード一覧

| モード               | インジケータ | 移行キー               | 役割                                           |
| :------------------- | :----------- | :--------------------- | :--------------------------------------------- |
| ノーマルモード       | `NORMAL`     | `Esc`                  | カーソル移動、削除、コピー、コマンド入力       |
| 挿入モード           | `INSERT`     | `i`, `a`, `o`, `I`, `A` | 通常の文字入力・編集                           |
| ビジュアルモード     | `VISUAL`     | `v`                    | 文字単位の範囲選択                             |
| 行ビジュアルモード   | `V-LINE`     | `V`                    | 行単位の範囲選択                               |
| 矩形ビジュアルモード | `V-BLOCK`    | `Ctrl-v`               | 矩形（BOX）ブロック単位の範囲選択              |
| コマンドラインモード | `:`          | `:`                    | exコマンド（`:w`, `:q`, `:help` 等）の実行    |

---

## 🏃 カーソル移動 (Normal Mode)

- `h` / `j` / `k` / `l`: 左 / 下 / 上 / 右
- `w` / `b` / `e`: 次の単語先頭 / 前の単語先頭 / 単語末尾
- `0` / `^` / `$`: 行頭 / 行頭空白直後 / 行末
- `gg` / `G`: ファイル先頭 / ファイル末尾
- `%`: 対応する括弧（`()`, `{}`, `[]`）へジャンプ

---

## ✂️ 編集・削除・ヤンク (Normal Mode)

- `x`: カーソル位置の1文字削除
- `dd` / `yy`: 1行削除 / 1行ヤンク（コピー）
- `d` + motion / `y` + motion: 範囲削除 / 範囲ヤンク（例: `dw`, `d$`）
- `p` / `P`: カーソル後 / カーソル前に貼り付け
- `u` / `Ctrl-r`: アンドゥ（元に戻す） / リドゥ（やり直し）
- `.` : 直前の変更を繰り返し実行

---

## 🔍 検索・ナビゲーション (Normal Mode)

- `/pattern`: 順方向検索
- `?pattern`: 逆方向検索
- `n` / `N`: 次の一致箇所 / 前の一致箇所へジャンプ
- `*` / `#`: カーソル下の単語を完全一致で前方／後方検索
- `g*` / `g#`: カーソル下の単語を部分一致で前方／後方検索
- `g<` / `g=`: カーソル下の単語を前方一致／後方一致で前方検索
- `g/pattern`: ローマ字日本語（Migemo）検索
- `f<char>` / `F<char>`: 指定文字（全角も自動マッチ）へ前方／後方ジャンプ
- `t<char>` / `T<char>`: 指定文字の直前／直後へ前方／後方ジャンプ
- `;` / `,`: 直前の文字検索を順方向／逆方向へ反復
- `Ctrl-]` / `Ctrl-t`: タグジャンプ（定義ジャンプ） / タグ復帰

---

## ⚡ 独自編集支援・マーク (Normal Mode)

- `#+` / `##`: 数値の加算（+1）、英字の順送り（`a` $\to$ `b`）
- `#-`: 数値の減算（-1）、英字の逆送り（`b` $\to$ `a`）
- `#!`: 真偽値の反転（`true` ⇄ `false`, `yes` ⇄ `no`）
- `@`: 直前編集位置へジャンプ
- `'@`: 直前編集行の先頭へジャンプ
- `=<char>`: 直前行の文字を現在行へ複製挿入
- `ma`〜`mz` / `mA`〜`mZ`: ローカルマーク / グローバルマーク登録
- `'a` / `` `a ``: マーク位置へジャンプ
- `:marks`: 登録済みマーク一覧の表示
- `:%s/pattern/expression/e`: 動的式評価による高度置換（式置換）
