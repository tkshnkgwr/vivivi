# 基本操作 & モード (Basic Usage & Modes)

`vivivi` の基本的な操作方法、各種モード、主要なキーバインドです。

---

## 🧭 主なモード一覧

| モード               | インジケータ | カーソル形状 | 移行キー             | 役割                                               |                                             |
| :------------------- | :----------- | :----------- | :------------------- | :------------------------------------------------- | :------------------------------------------ |
| ノーマルモード       | `NORMAL`     | ブロック (█) | `Esc`                | カーソル移動、削除、コピー、コマンド入力           |                                             |
| 挿入モード           | `INSERT`     | 縦線 (\      | )                    | `i`, `a`, `o`, `I`, `A`                            | 通常の文字入力・Tabキーによるタブ挿入・編集 |
| 置換モード           | `REPLACE`    | 下線 (_)     | `R`, 挿入中 `Insert` | 1文字ずつ上書き置換（Tabでタブ置換、`Esc` で復帰） |                                             |
| ビジュアルモード     | `VISUAL`     | ブロック (█) | `v`                  | 文字単位の範囲選択                                 |                                             |
| 行ビジュアルモード   | `V-LINE`     | ブロック (█) | `V`                  | 行単位の範囲選択                                   |                                             |
| 矩形ビジュアルモード | `V-BLOCK`    | ブロック (█) | `Ctrl-v`             | 矩形（BOX）ブロック単位の範囲選択                  |                                             |
| コマンドラインモード | `:`          | ブロック (█) | `:`                  | exコマンド（`:w`, `:q`, `:help` 等）の実行         |                                             |

## 🏃 カーソル移動 (Normal Mode)

- `h` / `j` / `k` / `l`: 左 / 下 / 上 / 右
- `w` / `b` / `e`: 次の単語先頭 / 前の単語先頭 / 単語末尾
- `W` / `B` / `E`: 次の大単語先頭 / 前の大単語先頭 / 大単語末尾（空白区切り）
- `0` / `^` / `$`: 行頭 / 行頭空白直後 / 行末
- `gg` / `G`: ファイル先頭 / ファイル末尾（行番号指定: `10G` で10行目へ）
- `%`: 対応する括弧（`()`, `{}`, `[]`）へジャンプ
- `{` / `}`: 前の段落（空行） / 次の段落（空行）へジャンプ
- `zz` / `zt` / `zb`: カーソル行を画面中央 / 最上段 / 最下段へスクロール調整

> [!TIP]
> **長行表示と水平スクロール／折り返し制御**:
> 通常時は `:se nowrap`（折り返しなし・水平スクロール追従）状態です。画面幅を超える長行でも、カーソルの横移動や `$`（行末移動）に合わせて画面が自動的に左右へ水平スクロールします。全角文字（幅2）やタブ文字（`tabstop` 設定幅）の表示幅（Visual Column）を正確に計算して描画クリッピングが行われます。
> 画面端での行折り返しを行いたい場合は、`:se wrap`（`:set wrap`）を実行することで折り返し表示へ動的に切り替えられます（`:se nowrap` で水平スクロール復帰、`:se wrap?` で状態確認）。

## ✂️ 編集・削除・ヤンク・インデント (Normal Mode)

- `x`: カーソル位置の1文字削除
- `dd` / `yy`: 1行削除 / 1行ヤンク（コピー）
- `d` + motion / `y` + motion: 範囲削除 / 範囲ヤンク（例: `dw`, `d$`, `diw`, `da"`）
- `c` + motion / `cc`: 範囲変更 / 1行変更（削除して挿入モードへ）
- `>>` / `<<`: 1行インデント（4スペース追加） / 1行アンインデント（最大4スペース削除）
- `>` + motion / `<` + motion: 指定範囲の行を一括インデント / アンインデント
- `gu` + motion / `gU` + motion: 指定範囲を一括小文字化 / 大文字化（例: `guw`, `gU$`, `gui"`）
- `guu` / `gUU`: 現在行を一括小文字化 / 大文字化
- `p` / `P`: カーソル後 / カーソル前に貼り付け
- `u` / `Ctrl-r`: アンドゥ（元に戻す） / リドゥ（やり直し）
- `.` : 直前の変更（文字削除、挿入、インデント、置換等）を繰り返し実行

## 📦 テキストオブジェクト (Text Objects)

オペレータ（`d`, `c`, `y`, `gu`, `gU`）やビジュアル選択（`v`）と組み合わせて、単語・引用符・括弧の内側や周囲を一括指定できます。

| オブジェクト | 内側 (inner) | 周囲 (around) | 対象範囲・説明                                              |
| :----------- | :----------- | :------------ | :---------------------------------------------------------- |
| **単語**     | `iw`         | `aw`          | 単語自身（inner） / 単語前後の空白を含む範囲（around）      |
| **大単語**   | `iW`         | `aW`          | 空白区切りの単語自身 / 前後の空白を含む範囲                 |
| **二重引用** | `i"`         | `a"`          | ダブルクォートの中身 / クォート記号および直後の空白を含む   |
| **一重引用** | `i'`         | `a'`          | シングルクォートの中身 / クォート記号および直後の空白を含む |
| **逆引用符** | `` i` ``     | `` a` ``      | バッククォートの中身 / クォート記号および直後の空白を含む   |
| **丸括弧**   | `i(` / `ib`  | `a(` / `ab`   | 丸括弧の中身 / `(...)` 括弧自身を含む                       |
| **中括弧**   | `i{` / `iB`  | `a{` / `aB`   | 中括弧の中身 / `{...}` 括弧自身を含む                       |
| **角括弧**   | `i[`         | `a[`          | 角括弧の中身 / `[...]` 括弧自身を含む                       |
| **山括弧**   | `i<`         | `a<`          | 山括弧の中身 / `<...>` 括弧自身を含む                       |

### 使用例
- `diw`: カーソル位置の単語を削除
- `ci"`: 引用符の中身を削除して即座に新しいテキストを入力
- `da(`: 括弧とその中身を丸ごと削除
- `v` + `i"`: 引用符の内側をビジュアル選択
- `gUiw`: カーソル下の単語を一括大文字化（`hello` $\to$ `HELLO`）

## 🔍 検索・ナビゲーション (Normal Mode)

- `/pattern`: 順方向検索（キーワード先頭文字へジャンプ、一致箇所ハイライト）
- `?pattern`: 逆方向検索（キーワード先頭文字へジャンプ、一致箇所ハイライト）
- `n` / `N`: 次の一致箇所 / 前の一致箇所へジャンプ
- `:noh` / `:nohl`: 検索ハイライト（`hlsearch`）を消去（ノーマルモードで `Esc` 2回連打でも消去可能）
- `*` / `#`: カーソル下の単語を完全一致で前方／後方検索
- `g*` / `g#`: カーソル下の単語を部分一致で前方／後方検索
- `g<` / `g=`: カーソル下の単語を前方一致／後方一致で前方検索
- `g/pattern` / `:migemo <query>`: ローマ字日本語（Migemo）検索（独自MIT辞書内蔵・外部SKK辞書対応）
- `f<char>` / `F<char>`: 指定文字（全角も自動マッチ）へ前方／後方ジャンプ
- `t<char>` / `T<char>`: 指定文字の直前／直後へ前方／後方ジャンプ
- `;` / `,`: 直前の文字検索を順方向／逆方向へ反復
- `Ctrl-]` / `Ctrl-t`: タグジャンプ（定義ジャンプ） / タグ復帰
- `Ctrl-w` + `h`/`j`/`k`/`l`/`w`: ウィンドウ間のフォーカス移動（幾何学的配置準拠）

---

## ⚡ 独自編集支援・マーク (Normal Mode)

- `#+` / `##`: 数値の加算（+1）、英字の順送り（`a` $\to$ `b`）
- `#-`: 数値の減算（-1）、英字の逆送り（`b` $\to$ `a`）
- `#!`: 真偽値の反転（`true` ⇄ `false`, `yes` ⇄ `no`）
- `@`: 直前編集位置へジャンプ
- `'@`: 直前編集行の先頭へジャンプ
- `=<char>`: 直前行の文字を現在行へ複製挿入
- `ma`〜`mz` / `mA`〜`mZ`: ローカルマーク / グローバルマーク登録
- `'a` / `` `a ``: マーク位置へジャンプ
- `:marks`: 登録済みマーク一覧の表示
- `:%s/pattern/expression/e`: 動的式評価による高度置換（式置換）

## 💾 ファイル操作・文字コード・改行指定

| コマンド                       | 動作説明                                                        |
| :----------------------------- | :-------------------------------------------------------------- |
| `:w [file]`                    | バッファを保存します（ファイル名指定で別名保存）。              |
| `:q` / `:q!`                   | エディタを終了します（未保存の変更がある場合は `:q!` で破棄）。 |
| `:wq` / `:x`                   | バッファを保存してエディタを終了します。                        |
| `:e ++enc=<enc> [file]`        | 指定した文字コード（`utf-8`, `sjis`, `euc-jp`）で再読込します。 |
| `:set fenc=<enc>`              | 保存時の文字コード（`utf-8`, `sjis`, `euc-jp`）を指定します。   |
| `:set ff=unix` / `:set ff=dos` | 改行コードを LF (Unix) または CRLF (DOS/Windows) に変換します。 |
| `:<行番号>`                    | 指定行（例: `:42`, `:1`）へ直接ジャンプします。                 |
| `:%s/before/after/[flags]`     | バッファ全体の文字列置換（`g`:全置換, `i`:無視, `e`:式置換）。  |
| `:s/before/after/[flags]`      | カレント行の文字列置換を行います。                              |
| `:recover`                     | スワップファイル（`.swp`）から未保存データを復元します。        |
