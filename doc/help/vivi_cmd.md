# ViVi独自vi拡張コマンド & ナビゲーション (ViVi Extensions)

ViVi 3 / ViVi 4 / OpenViVi に由来する、強力かつ快適なviコマンド拡張機能およびナビゲーション機能の解説です。

---

## 📖 機能一覧

| コマンド / キー             | 種別               | 概要                                                              |
| :-------------------------- | :----------------- | :---------------------------------------------------------------- |
| `f`, `F`, `t`, `T`, `;`, `,`| 全角文字自動マッチ | 半角英数記号入力時に全角数字・全角括弧・全角記号へも透過マッチ     |
| `*`, `#`, `g*`, `g#`        | カーソル単語検索   | カーソル位置の単語を完全一致または部分一致で前後検索              |
| `g<`, `g=`                  | 前後方一致検索     | カーソル位置の単語を前方一致（プレフィックス）または後方一致検索  |
| `#+`, `##`, `#-`            | 数値・英字増減     | カーソル位置の数値加減算、アルファベット順送り（`a`⇄`b`）         |
| `#!`                        | 真偽値トグル       | `true` ⇄ `false`, `yes` ⇄ `no` 等の真偽値反転                     |
| `@`, `'@`, `` `@ ``         | 直前編集位置復帰   | 直前に編集を行った文字位置・行への即時ジャンプ                    |
| `=<char>`                   | 直前行文字列複製   | 直前の行の現在カーソル列以降の文字を指定文字まで複製挿入          |
| `mA`〜`mZ`, `ma`〜`mz`      | マーク登録         | 小文字ローカルマーク、大文字ワークスペース永続グローバルマーク    |
| `'a`, `` `a ``, `:marks`    | マークジャンプ     | 登録マーク位置へジャンプ、マーク一覧表示                          |
| `Ctrl-]`, `Ctrl-t`, `:tag`  | タグジャンプ       | `tags` ファイルおよび構文解析に基づく関数・構造体定義ジャンプ     |

---

## 1. fFtT 全角文字自動マッチ (`fFtT`)

通常のviでは `f(` と打鍵すると半角の `(` のみにジャンプします。
`vivivi` では、半角文字を入力した場合に対応する全角文字（全角括弧 `（`、全角数字 `１`、全角記号 `：` など）にも自動的にマッチします。

- **`f<char>`**: 行末方向へ `<char>`（または対応する全角文字）を検索してジャンプ
- **`F<char>`**: 行頭方向へ `<char>`（または対応する全角文字）を検索してジャンプ
- **`t<char>`**: 行末方向へ `<char>` の直前へジャンプ
- **`T<char>`**: 行頭方向へ `<char>` の直後へジャンプ
- **`;`**: 直前の文字検索を順方向へ繰り返す
- **`,`**: 直前の文字検索を逆方向へ繰り返す
- **オペレータ連携**: `df)` や `ct]` などの削除・変更コマンドでも全角文字が正しく対象に含まれます。

## 2. カーソル単語の前後方検索 & 前後方一致検索

カーソルが乗っている単語をそのままキー1つで検索します。

- **`*`**: カーソル下の単語を完全一致（単語境界 `\bword\b`）で前方検索
- **`#`**: カーソル下の単語を完全一致で後方検索
- **`g*`**: 単語境界なし（部分一致）で前方検索
- **`g#`**: 単語境界なし（部分一致）で後方検索
- **`g<`**: カーソル下の単語を**前方一致（プレフィックス一致）**で前方検索
- **`g=`**: カーソル下の単語を**後方一致（サフィックス一致）**で前方検索

---

## 3. 数値・英字インクリメント/デクリメント & 真偽値トグル

カーソル位置の数値やコード識別子をその場で直接書き換えます。

- **`#+` / `##`**:
  - 数値の場合: `+1` 加算（例: `10` $\to$ `11`）
  - 英字の場合: アルファベット順送り（`a` $\to$ `b`, `z` $\to$ `a`）
- **`#-`**:
  - 数値の場合: `-1` 減算（例: `10` $\to$ `9`）
  - 英字の場合: アルファベット逆送り（`b` $\to$ `a`, `a` $\to$ `z`）
- **`#!`**:
  - 真偽値の反転トグル:
    - `true` ⇄ `false`
    - `True` ⇄ `False`
    - `TRUE` ⇄ `FALSE`
    - `yes` ⇄ `no`
    - `on` ⇄ `off`

---

## 4. 直前編集位置復帰 & 直前行文字列複製

- **`@`**:
  - 直前に文字を挿入、削除、または置換した位置へ瞬時にカーソルを復帰させます。
  - 離れた場所を参照した後に、作業していた位置へワンキーで戻ることができます。
- **`'@` / `` `@ ``**:
  - 直前に編集した行の先頭へジャンプします。
- **`=<char>`**:
  - 1つ上の行の現在列にある文字から、指定した `<char>` までの文字列（または改行まで）をカレント行へ複製して挿入します。

---

## 5. グローバルマーク (`mA`〜`mZ`, `:marks`)

- **`ma`〜`mz`**: カレントバッファ内の現在行・現在列にローカルマークを登録。
- **`mA`〜`mZ`**: ファイルパスを保持する大文字のグローバルマークを登録。
- **`'a` / `` `a ``**: マークした位置へジャンプ（大文字マークは別ファイルへも自動切り替え）。
- **`:marks`**: 登録されているマーク一覧をステータス行に表示。

---

## 6. タグジャンプ (`Ctrl-]`, `Ctrl-t`, `Ctrl-[`, `:tag`, `:tags`)

ソースコードの関数や構造体、変数定義へジャンプします。

- **`Ctrl-]`**: カーソル下の単語の定義元へジャンプ。
  - プロジェクト直下の `tags` ファイルを検索。
  - `tags` ファイルが存在しない場合でも、組み込みの構文解析機能（Rust, Python, Markdown等）により同一バッファ内の定義位置へフォールバックジャンプ。
- **`Ctrl-t` / `Ctrl-[`**: タグスタックをポップし、ジャンプ前の元の位置へ復帰。
- **`:tag <name>`**: 指定した識別子名 `<name>` の定義位置へジャンプ。
- **`:tags`**: 現在のタグジャンプ履歴スタックの一覧を表示。
