# 視覚・編集支援機能 (Visual & Editing Enhancements)

`vivivi` では、コーディングや日本語テキスト執筆を快適にする多彩な視覚支援・履歴管理機能を提供しています。

---

## 🎨 1. 変更行ガター強調表示 (Change Markers)

バッファ内の各行の編集・保存状態を、行番号の右隣のガターバー（縦線エリア）にリアルタイムで色分け表示します。

| ガター記号 | 色          | 意味                                                           |
| :--------- | :---------- | :------------------------------------------------------------- |
| `▌`        | 黄色 (太字) | **未保存変更行**: ロードまたは前回保存以降に編集・追加された行 |
| `▌`        | 緑色 (太字) | **保存済み行**: 今回のセッションで編集され、すでに保存された行 |
| `│`        | 薄いグレー  | **変更なし**: 元ファイルから変更されていない通常の行           |

### コマンド
- `:set gutter` / `:gutter`: ガター強調表示を有効化（デフォルトで有効）
- `:set nogutter` / `:nogutter`: ガター強調表示を無効化

---

## 📁 2. 最近使ったファイル (MRU) & お気に入り (Favorites)

開いたファイルの履歴およびピン留めした「お気に入りファイル」を、ポップアップダイアログからワンキーで高速オープンできます。

### 起動ショートカット・コマンド
- **`F7`** または **`:recent`** / **`:mru`**: 最近使ったファイル＆お気に入り一覧モーダルを開く
- **`:fav`** / **`:favorite`** / **`:addfav`**: 現在開いているファイルをお気に入りに登録／解除トグル
- **`:e <path>`** / **`:edit <path>`**: 指定したパスのファイルを読み込んで開く

### モーダル操作キー
- **`↑` / `↓`** または **`k` / `j`**: ファイル一覧のカーソル移動
- **`Enter`**: 選択したファイルを開く
- **`f`**: 選択中ファイルのお気に入り登録／解除（★マーク）
- **`d`** または **`Delete`**: 選択中ファイルを履歴から削除
- **`Esc`** または **`q`**: モーダルを閉じる

> [!NOTE]
> 履歴・お気に入りは `%USERPROFILE%\.vivivi\recent.txt`（Linux/macOS では `~/.vivivi/recent.txt`）に自動保存され、エディタを再起動しても保持されます。

## 🔲 3. 不可視文字・空白文字の可視化 (`:set list`)

全角スペースやタブ、行末スペース、改行コードを視覚記号として画面上に浮かび上がらせます。
日本語文章やコード内で予期せぬ全角スペースの混入によるシンタックスエラーを未然に防止します。

| 不可視文字   | 表示記号 | スタイル           | 役割・目的                                     |
| :----------- | :------- | :----------------- | :--------------------------------------------- |
| **全角空白** | `□`      | 赤色太字・強調背景 | 日本語編集で最も事故になりやすい全角空白を警告 |
| **タブ文字** | `▸---`   | 暗いグレー         | インデント幅（4幅）に合わせた矢印と破線表示    |
| **末尾空白** | `·`      | 暗いグレー         | 行末に残ってしまった余分なスペースを可視化     |
| **改行記号** | `$`      | 暗いグレー         | 行末の確定位置を明示                           |

### コマンド
- `:set list` / `:list`: 不可視文字の可視化を有効化
- `:set nolist` / `:nolist`: 不可視文字の可視化を無効化（通常表示に戻す）

## 🛠️ 4. 統合ツールコマンド連携

フェーズ4.5で実装された各種TUI管理ツールも、Exコマンドから直接呼び出し可能です。

- **`:todo`** / **`:undone`**: バッファ内の `TODO:`, `FIXME:`, `NOTE:`, `HACK:` を一括抽出してプレビュー表示
- **`:diff`**: ディスク上の保存済みファイルと現在編集中のバッファとのUnified Diff差分をプレビュー表示
- **`:difflog`**: 編集セッション世代バックアップ履歴（`.difflog`）の一覧を表示
- **`:filer`** / **`:explore`**: 左右2画面のディレクトリファイラーを起動（Tab切替・1キーファイル操作・ファイルオープン）
- **`:preview`** / **`:print`**: Markdown整形・ページ分割・ヘッダー/フッター付き印刷プレビューを表示

## 🔲 5. 矩形選択一括編集 (Visual Block Operations)

`Ctrl-v` による矩形選択モードにおいて、複数行にまたがる列方向の一括編集操作をサポートしています。

| キー操作         | 動作説明                                                         |
| :--------------- | :--------------------------------------------------------------- |
| `I<text>Esc`     | 矩形選択されたすべての行の左端に、入力したテキストを一括挿入します。 |
| `A<text>Esc`     | 矩形選択されたすべての行の右端に、入力したテキストを一括追加します。 |
| `c<text>Esc`     | 矩形選択された領域の文字を一括削除し、入力したテキストで置換します。 |
| `r<char>`        | 矩形選択領域内のすべての文字を指定した 1 文字で一括塗りつぶします。 |
| `d` / `x`        | 矩形選択された領域の文字を一括削除し、行内の後続文字を左へ詰めます。 |

### 使用例
- **コメントアウトの一括追加**: `Ctrl-v` で複数行の先頭1文字を選択し、`I// <Esc>` を入力すると全行の先頭に `// ` が一括挿入されます。
- **行末セミコロンの一括追加**: `Ctrl-v` で複数行の行末位置を選択し、`A;<Esc>` を入力すると全行の行末に `;` が一括追加されます。
- **矩形領域の空白埋め**: `Ctrl-v` で範囲選択し、`r `（r + スペース）で矩形領域を一括クリアできます。
