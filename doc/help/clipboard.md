# システム共有クリップボード連携 (Clipboard Integration)

`vivivi` では、Vim / Neovim 互換のクリップボードレジスタ（`+` / `*`）および `:set clipboard=unnamed` オプションを通じて、OS（Windows / macOS / Linux）のシステムクリップボードとシームレスに文字列をやり取りできます。

---

## 📋 クリップボードレジスタの明示操作

Vi のレジスタ指定構文（`"` + レジスタ名）により、OS クリップボードと直接ヤンク（コピー）＆プット（貼り付け）が行えます。

| キー操作         | 動作説明                                                         |
| :--------------- | :--------------------------------------------------------------- |
| `"+y` / `"*y`    | 選択範囲または対象オブジェクトを OS クリップボードへコピーします。 |
| `"+p` / `"*p`    | OS クリップボードの内容をカレント位置へ貼り付けます。             |
| `"+P` / `"*P`    | OS クリップボードの内容をカレント位置の直前へ貼り付けます。       |

---

## ⚡ デフォルト無名レジスタの連携 (`clipboard=unnamed`)

Vim 同様、無名レジスタ（通常の一文字削除 `x` やヤンク `y`）を自動的に OS クリップボードと連動させることができます。

### ex コマンドでの切り替え
- `:set clipboard=unnamed`: 通常の `y`（ヤンク）や `p`（プット）が自動的に OS クリップボードと同期されます。
- `:set clipboard=unnamedplus`: `+` レジスタおよび無名レジスタの両方を OS クリップボードと同期します。
- `:set clipboard=none`: システム共有を解除し、エディタ内部の独立レジスタとして動作させます。

### `config.toml` による永続化
`%USERPROFILE%\.vivivi\config.toml` に以下を記述することで、エディタ起動時から常にクリップボード共有を有効化できます。

```toml
[editor]
clipboard = "unnamed"
```
