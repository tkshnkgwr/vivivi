# 罫線モード & 罫線保護編集 (Keisen Mode)

ViViおよびOpenViViの代名詞とも言える、Unicode二重・単線罫線の対話的描画および罫線保護編集機能です。

---

## 🚀 罫線モードの切り替え

- **ショートカット**: `F5`
- **exコマンド**: `:keisen`

ステータスバーに `[罫線]` インジケータが表示されます。

---

## ✏️ 罫線描画・消去操作

| 操作キー                         | 動作                                                           |
| :------------------------------- | :------------------------------------------------------------- |
| `Ctrl + 上/下矢印`               | 縦方向（│）の罫線を引く（幾何学的自動結合・行自動拡張）         |
| `Ctrl + 左/右矢印`               | 横方向（─）の罫線を引く（幾何学的自動結合）                     |
| `Alt + 矢印キー`                 | `Ctrl + 矢印キー` と同様に罫線を描画                             |
| `Shift + 矢印キー`               | 移動方向にある罫線を消去し、周囲の接続関係を自動再計算して修復   |
| 矢印キー単独 / `h`/`j`/`k`/`l`   | 通常のカーソル移動（罫線モード時でも線を描画しない）             |

> [!TIP]
> **幾何学的角結合（糸のほつれ解消）**: 四角形を描画した際、上下左右の隣接セルの実際の接続状況を幾何学的に検査し、曲がり角の余計な突き抜け成分（T字路）を自動消去して完璧な角（`┌─┐` / `│ │` / `└─┘`）に結合します。最下行を超えて下に線を引く場合も自動で行が追加拡張されます。

## 🛡️ 罫線保護編集 (Keisen Protected Edit)

罫線モードが有効な状態で、罫線で囲まれた枠内（`│ ... │`）にカーソルを置き、挿入モードで文字入力または削除を行うと機能します。

### 1. 文字入力時の保護
- 枠内で文字を入力すると、カーソル位置から右枠線までの間にある**末尾の空白文字が自動的に1文字分削られます**。
- これにより、右側の縦枠線が右に押し出されることなく、外枠の位置が完全にキープされます。
- ※枠内に空白（余白）が1文字もない場合は、枠線の破壊を防ぐため入力を自動的に拒否します。

### 2. 文字削除時の保護
- 枠内で `Backspace` または `Delete` を押すと、削除された文字の分だけ**右枠線の直前に半角スペースが自動補填されます**。
- これにより、右側の縦枠線が左に引き込まれることなく、外枠の位置が完全にキープされます。
- ※左端の枠線や右端の枠線自体の誤削除は自動的に防止されます。

---

## 📐 枠内テキストの整列

罫線枠内のテキストを綺麗に揃えるコマンドです。

- `:align left` : 枠内テキストを左寄せ
- `:align right`: 枠内テキストを右寄せ
- `:align center`: 枠内テキストを中央揃え
